## 3. ภาพใหญ่: เกมต้อง "จำ" อะไรบ้าง

โปรแกรมสองอันก่อน กดปุ่มทีไรก็คำนวณจบในครั้งเดียว แต่เกมต้อง **จำข้อมูลข้ามการกดหลายครั้ง** เช่น เลขลับคืออะไร ทายไปแล้วกี่ครั้ง สิ่งที่ต้องจำนี้เรียกว่า **state** (สเตต = สถานะ)

| ตัวแปร | จำอะไร |
|---|---|
| `secret` | เลขลับ |
| `tries` | ทายไปแล้วกี่ครั้ง |
| `low`, `high` | ขอบล่าง/ขอบบนของช่วงที่ยังเป็นไปได้ |
| `game_over` | จบเกมหรือยัง (ถ้าจบแล้วห้ามทายต่อ) |

## 5. อธิบายโค้ดทีละส่วน

### 5.1 นำเข้าเครื่องมือ

```python
import tkinter as tk
import random
```

- `random` (แรน-ดอม = สุ่ม) เป็นเครื่องมือสุ่มตัวเลข เหมาะกับเกม
  - (ในโปรเจกต์รหัสผ่านใช้ `secrets` เพราะงานความปลอดภัยต้องสุ่มแบบเดาไม่ได้ แต่เกมไม่ต้องขนาดนั้น)

### 5.2 ค่าคงที่และตัวแปรสถานะ

```python
MIN_NUMBER = 1
MAX_NUMBER = 100
MAX_TRIES = 7

secret = 0
tries = 0
low = MIN_NUMBER
high = MAX_NUMBER
game_over = False
```

- `MIN` มาจาก **min**imum (มิ-นิ-มัม = ต่ำสุด), `MAX` มาจาก **max**imum (แม็ก-ซิ-มัม = สูงสุด)
- ตั้งเป็นค่าคงที่ไว้ด้านบน ถ้าอยากเปลี่ยนเกมเป็น 1–1000 แก้แค่บรรทัดเดียว
- ตัวแปรสถานะประกาศไว้ **นอกฟังก์ชัน** เพื่อให้ทุกฟังก์ชันเห็นและใช้ร่วมกันได้ ค่าเริ่มต้นใส่ไว้ก่อนเฉยๆ เดี๋ยว `new_game()` จะตั้งค่าจริงให้

### 5.3 ฟังก์ชัน `check_guess` (สมองของเกม)

```python
def check_guess(guess, answer):
    if guess < answer:
        return "น้อยไป"
    elif guess > answer:
        return "มากไป"
    else:
        return "ถูกต้อง"
```

- `elif` มาจาก **el**se **if** (เอล-อิฟ = ถ้าไม่ใช่ข้อบน แล้วถ้า...) ใช้เมื่อมีหลายกรณี
- ฟังก์ชันนี้ไม่ยุ่งกับหน้าจอ รับเลข 2 ตัว คืนคำตอบเป็นข้อความ

### 5.4 ฟังก์ชัน `new_game` และคำว่า `global`

```python
def new_game():
    global secret, tries, low, high, game_over
    secret = random.randint(MIN_NUMBER, MAX_NUMBER)
    tries = 0
    low = MIN_NUMBER
    high = MAX_NUMBER
    game_over = False
    ...
```

- **`global` สำคัญมาก** ตามปกติถ้าเรา `ใส่ค่า` ให้ตัวแปรในฟังก์ชัน Python จะถือว่าเป็น **ตัวแปรใหม่ของฟังก์ชันนั้นเอง** (เรียกว่า local โล-เคิล = เฉพาะที่) ซึ่งหายไปเมื่อฟังก์ชันจบ
  - การเขียน `global secret` เป็นการบอก Python ว่า "`secret` ที่จะแก้ คือตัวที่อยู่ข้างนอก ตัวที่ทั้งโปรแกรมใช้ร่วมกัน"
  - 🏠 **เปรียบเทียบ:** ตัวแปร local เหมือนกระดาษโน้ตในห้องตัวเอง ออกจากห้องแล้วก็ทิ้ง ส่วนตัวแปร global เหมือนกระดานหน้าบ้านที่ทุกคนเห็น ถ้าจะเขียนบนกระดานหน้าบ้านต้องบอกก่อนว่า "ผมจะเขียนบนกระดานนะ"
  - ถ้าลืม `global` เกมจะไม่จำอะไรเลย เช่น `tries` จะไม่เพิ่มขึ้น
- `random.randint(1, 100)` โดย `randint` มาจาก **rand**om **int**eger (แรน-ดอม อิน-ทิ-เจอร์ = สุ่มจำนวนเต็ม) สุ่มเลขตั้งแต่ 1 ถึง 100 **รวมทั้ง 1 และ 100**
- ส่วนที่เหลือของฟังก์ชันล้างประวัติ ล้างช่องกรอก แล้วเรียก `update_status()` ให้หน้าจอแสดงค่าเริ่มต้น

### 5.5 ฟังก์ชัน `on_guess` (กดทาย)

```python
def on_guess(event=None):
    global tries, low, high, game_over
    if game_over:
        return
```

- ใส่ `global` เฉพาะตัวที่ฟังก์ชันนี้ **แก้ค่า** (`secret` แค่อ่าน ไม่ได้แก้ จึงไม่ต้องใส่)
- ถ้าเกมจบแล้ว ไม่ทำอะไร (ต้องกด "เล่นใหม่" ก่อน)

```python
    text = guess_entry.get().strip()
    guess_entry.delete(0, tk.END)

    if not text.isdigit():
        message_label.config(text="กรุณาพิมพ์ตัวเลขเท่านั้น", fg="red")
        return

    guess = int(text)
    if guess < low or guess > high:
        message_label.config(text=f"ลองเลขระหว่าง {low} – {high} สิ (ไม่นับครั้งนี้)", fg="red")
        return
```

- อ่านค่าแล้วล้างช่องทันที ผู้เล่นจะได้พิมพ์ครั้งต่อไปได้เลย
- ตรวจ 2 ชั้น: เป็นตัวเลขไหม และอยู่ในช่วงที่ยังเป็นไปได้ไหม ถ้าทายนอกช่วง (เช่น รู้แล้วว่ามากกว่า 50 แต่ยังทาย 30) ไม่นับครั้ง เพราะเป็นการทายที่เสียเปล่า

```python
    tries = tries + 1
    result = check_guess(guess, secret)
    history_listbox.insert(tk.END, f"ครั้งที่ {tries}:  {guess}  →  {result}")

    if result == "ถูกต้อง":
        message_label.config(text=f"🎉 ถูกต้อง! เลขลับคือ {secret} ใช้ไป {tries} ครั้ง", fg="green")
        game_over = True
        return
```

- นับครั้ง ตรวจผล และบันทึกลงกล่องประวัติ
- ถ้าถูก ตั้ง `game_over = True` แล้วจบ

```python
    if result == "น้อยไป":
        low = guess + 1
    else:
        high = guess - 1
```

- **ส่วนนี้คือหัวใจของการบีบช่วง:** ถ้าทาย 50 แล้วได้ "น้อยไป" แปลว่าเลขลับมากกว่า 50 ขอบล่างใหม่จึงเป็น 51 (`+ 1` เพราะ 50 ไม่ใช่คำตอบแน่ๆ แล้ว)

```python
    if tries >= MAX_TRIES:
        message_label.config(text=f"😢 หมดโอกาสแล้ว เลขลับคือ {secret}", fg="red")
        game_over = True
    else:
        message_label.config(text=f"{guess} {result}", fg="orange")
    update_status()
```

- `>=` แปลว่า "มากกว่าหรือเท่ากับ" ถ้าครบ 7 ครั้งแล้วยังไม่ถูก ก็แพ้และเฉลย

## 6. แนวคิด CS: Binary Search (ค้นหาแบบแบ่งครึ่ง)

**Binary** (ไบ-นา-รี) แปลว่า "สอง" เพราะทุกครั้งเราแบ่งช่วงเป็นสองส่วนแล้วทิ้งไปครึ่งหนึ่ง

**วิธีเล่นให้ชนะเสมอ:** ทายเลข **ตรงกลางช่วง** ทุกครั้ง

| ครั้งที่ | ช่วงที่เหลือ | ทาย (ตรงกลาง) | ผล (สมมติเลขลับ = 73) |
|---|---|---|---|
| 1 | 1–100 | 50 | น้อยไป |
| 2 | 51–100 | 75 | มากไป |
| 3 | 51–74 | 62 | น้อยไป |
| 4 | 63–74 | 68 | น้อยไป |
| 5 | 69–74 | 71 | น้อยไป |
| 6 | 72–74 | 73 | ถูกต้อง 🎉 |

**ทำไม 7 ครั้งพอเสมอ?** ทุกครั้งช่วงเหลือครึ่งหนึ่ง: 100 → 50 → 25 → 13 → 7 → 4 → 2 → 1 ใช้ไม่เกิน 7 ครั้ง เพราะ 2⁷ = 128 ซึ่งมากกว่า 100

> 💡 **ทำไมเรื่องนี้สำคัญในชีวิตจริง?** ถ้าทายทีละเลข 1, 2, 3, ... (เรียกว่า linear search ลิ-เนีย เสิร์ช = ค้นหาแบบเรียงตัว) อาจต้องทายถึง 100 ครั้ง แต่ binary search ใช้แค่ 7 ครั้ง ถ้าข้อมูลมีล้านตัว ใช้แค่ประมาณ **20 ครั้ง**! โปรแกรมค้นหาชื่อในรายชื่อที่เรียงแล้วก็ใช้หลักนี้ (มีเงื่อนไขว่า **ข้อมูลต้องเรียงลำดับก่อน**)

## 7. คำถามที่กรรมการอาจถาม และแนวตอบ

**Q1: เกมนี้เกี่ยวกับวิทยาการคอมพิวเตอร์ยังไง?**
> วิธีทายให้ชนะเร็วที่สุดคือ Binary Search คือทายตรงกลางช่วงแล้วตัดทิ้งไปครึ่งหนึ่งทุกครั้ง ซึ่งเป็นวิธีค้นหาข้อมูลที่เรียงแล้วในโปรแกรมจริงครับ

**Q2: ทำไมตั้งโอกาสไว้ 7 ครั้ง?**
> เพราะถ้าใช้ Binary Search กับเลข 1–100 ช่วงจะเหลือครึ่งทุกครั้ง ใช้ไม่เกิน 7 ครั้งก็เหลือเลขเดียวแน่นอน เพราะ 2 ยกกำลัง 7 คือ 128 ซึ่งมากกว่า 100 ครับ

**Q3: `global` ใช้ทำอะไร?**
> เกมต้องจำค่า เช่น จำนวนครั้งที่ทาย ข้ามการกดปุ่มหลายครั้ง ผมเลยเก็บไว้นอกฟังก์ชัน และใช้ `global` บอก Python ว่าจะแก้ตัวแปรข้างนอกนั้น ไม่ใช่สร้างตัวแปรใหม่ในฟังก์ชันครับ

**Q4: ถ้าผู้เล่นทายเลขที่รู้อยู่แล้วว่าผิด จะเกิดอะไรขึ้น?**
> ผมเช็กว่าเลขอยู่ในช่วงที่ยังเป็นไปได้ไหม ถ้าไม่อยู่จะเตือนและไม่นับครั้งนั้นครับ

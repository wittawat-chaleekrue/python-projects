## 4. อธิบายโค้ดทีละส่วน

### ส่วนหัว: ค่าตั้งต้น

```python
WORK_MINUTES = 25
BREAK_MINUTES = 5
```
ค่าคงที่ (ตัวพิมพ์ใหญ่หมด = ตกลงกันว่าไม่เปลี่ยนระหว่างโปรแกรมทำงาน) ถ้าอยากอ่าน 50 นาทีพัก 10 นาที ก็แก้แค่ 2 บรรทัดนี้ ไม่ต้องไล่แก้ทั้งไฟล์

```python
seconds_left = WORK_MINUTES * 60
is_running = False
is_work_time = True
rounds_done = 0
timer_id = None
```
- `seconds_left` = เก็บเวลาเป็น **วินาที** (25 × 60 = 1500) เพราะนับลดทีละ 1 วินาทีได้ง่ายกว่าเก็บเป็นนาที
- `is_running` / `is_work_time` = ตัวแปรแบบ **True/False** (ทรู = จริง / ฟอลส์ = เท็จ) ตั้งชื่อขึ้นต้นด้วย `is_` (อิส = เป็น/ใช่ไหม) จะอ่านเหมือนคำถาม เช่น `is_running` = "กำลังเดินอยู่ใช่ไหม?"
- `timer_id` = ตอนแรกยังไม่มีงานที่ฝากไว้ เลยเป็น `None` (นัน = ไม่มีอะไร)

### ส่วนที่ 1: `show_time()` — แสดงผลบนจอ

```python
minutes = seconds_left // 60
seconds = seconds_left % 60
```
แปลงวินาทีกลับเป็น **นาที:วินาที** เช่น เหลือ 754 วินาที
- `754 // 60` = **12** (`//` = หารแล้ว**ปัดเศษทิ้ง** ได้กี่นาทีเต็ม)
- `754 % 60` = **34** (`%` = หารแล้วเอา**เศษ** เหลือกี่วินาที)
- จึงแสดงผลเป็น **12:34**

> เปรียบเทียบ: มีเงิน 754 บาท แลกเป็นแบงก์ 60 ได้ 12 ใบ (`//`) เหลือเศษ 34 บาท (`%`)

```python
label_time.config(text=f"{minutes:02d}:{seconds:02d}")
```
- `:02d` = แสดงเป็นตัวเลข (`d` = **d**ecimal เดซิมอล = เลขฐานสิบ) ให้กว้าง **2 หลัก** ถ้าไม่ครบให้เติม **0** ข้างหน้า
- ทำให้ 5 นาที 7 วินาที แสดงเป็น `05:07` ไม่ใช่ `5:7`
- `.config(...)` = เปลี่ยนข้อความของป้ายที่สร้างไว้แล้ว

```python
if is_work_time:
    label_mode.config(text="📖 ช่วงอ่านหนังสือ", fg="red")
else:
    label_mode.config(text="☕ ช่วงพัก", fg="green")
```
เปลี่ยนป้ายบอกช่วงและสีตัวอักษร (`fg` = **f**ore**g**round ฟอร์-กราวนด์ = สีด้านหน้า หรือสีตัวอักษร)

### ส่วนที่ 2: `tick()` — หัวใจของโปรแกรม ⭐

```python
def tick():
    global seconds_left, is_work_time, rounds_done, timer_id
```
`global` = บอก Python ว่า "จะแก้ตัวแปรตัวนอกนะ ไม่ได้สร้างตัวใหม่ในฟังก์ชัน" (เหมือนที่ใช้ใน queue_system)

```python
    if seconds_left > 0:
        seconds_left = seconds_left - 1
```
ถ้ายังมีเวลาเหลือ → ลดลง 1 วินาที

```python
    else:
        window.bell()
        if is_work_time:
            rounds_done = rounds_done + 1
            is_work_time = False
            seconds_left = BREAK_MINUTES * 60
            messagebox.showinfo(...)
        else:
            is_work_time = True
            seconds_left = WORK_MINUTES * 60
            messagebox.showinfo(...)
```
ถ้าเวลาเหลือ 0 → ส่งเสียงเตือน แล้วดูว่าเพิ่งจบช่วงไหน
- จบช่วง**อ่าน** → นับรอบเพิ่ม 1, สลับเป็นช่วงพัก, ตั้งเวลา 5 นาที
- จบช่วง**พัก** → สลับเป็นช่วงอ่าน, ตั้งเวลา 25 นาที (ช่วงพักไม่นับรอบ)

```python
    show_time()
    timer_id = window.after(1000, tick)
```
**นี่คือความรู้ใหม่ของโปรเจคนี้** 👇

`window.after(1000, tick)` แปลเป็นภาษาคนว่า **"หลังจาก (after) ผ่านไป 1000 มิลลิวินาที ให้เรียกฟังก์ชัน tick"**
- ตัวเลขเป็น **มิลลิวินาที**: 1000 มิลลิวินาที = 1 วินาที
- ใส่ `tick` **ไม่มีวงเล็บ** เพราะเรา "ฝากชื่อฟังก์ชันไว้" ให้ระบบเป็นคนเรียกทีหลัง (เหมือน `command=` ของปุ่ม)
- `after` จะคืน **เลขบัตรคิว** มาให้ เราเก็บไว้ใน `timer_id` เพื่อเอาไปยกเลิกได้ภายหลัง

**ทำไม tick เรียกตัวเองซ้ำได้เรื่อย ๆ?**
tick ทำงาน → ก่อนจบก็ฝากงานว่า "อีก 1 วินาทีมาเรียกฉันอีกนะ" → 1 วินาทีต่อมา tick ทำงานอีก → ฝากอีก → ... วนแบบนี้ไปเรื่อย ๆ นาฬิกาจึงเดินทีละวินาที

> เปรียบเทียบ: เหมือนตั้งปลุกมือถือ "อีก 1 นาทีปลุกนะ" พอปลุกก็ทำงาน แล้วตั้งปลุกอีก 1 นาทีต่อ ระหว่างรอปลุก เราไปทำอย่างอื่นได้ ไม่ต้องนั่งจ้องนาฬิกา

**ทำไมไม่ใช้ `time.sleep(1)` (สลีป = นอนหลับ)?** ← อาจารย์ชอบถามข้อนี้

โปรแกรม tkinter มี **event loop** (อี-เวนท์ ลูป = วงรอบคอยรอเหตุการณ์) ที่เริ่มทำงานตอน `window.mainloop()` ทำหน้าที่วนดูอยู่ตลอดว่า "มีใครกดปุ่มไหม? ต้องวาดหน้าจอใหม่ไหม? มีงานที่ฝากไว้ถึงเวลาหรือยัง?"
- ถ้าใช้ `sleep(1)` → โปรแกรม**หลับจริง ๆ** event loop หยุดไปด้วย → หน้าจอ**ค้าง** กดปุ่มอะไรก็ไม่ติด (บน Mac จะเห็นลูกบอลสีรุ้งหมุน)
- ถ้าใช้ `after(1000, ...)` → แค่**ฝากงานไว้**แล้วปล่อยให้ event loop ทำงานต่อ → หน้าจอยังกดได้ปกติ

> เปรียบเทียบ: พนักงานร้านอาหาร (event loop) คนเดียว ถ้าเขาไปยืนรอหน้าเตาอบ 10 นาที (sleep) ลูกค้าคนอื่นก็ไม่มีใครรับออเดอร์ แต่ถ้าตั้งนาฬิกาเตาอบไว้ (after) แล้วไปรับออเดอร์ต่อ พอเตาดังค่อยกลับมาหยิบ ร้านก็เดินต่อได้

### ส่วนที่ 3: ฟังก์ชันของปุ่ม

#### `start()` — ปุ่มเริ่ม
```python
if is_running:
    return
is_running = True
timer_id = window.after(1000, tick)
```
- ถ้านาฬิกาเดินอยู่แล้ว → ไม่ทำอะไร (`return` ออกเลย)
- **ทำไมต้องกันกดซ้ำ?** ถ้ากดเริ่ม 2 ครั้ง จะมีงาน tick ถูกฝากไว้ **2 สาย** แต่ละสายลดเวลาวินาทีละ 1 → รวมกันลดวินาทีละ 2 นาฬิกาจะเดินเร็วขึ้น 2 เท่า (ลองลบ 2 บรรทัดแรกออกแล้วกดเริ่มรัว ๆ ดู จะเห็นเอง)

#### `pause()` — ปุ่มหยุด
```python
if is_running:
    window.after_cancel(timer_id)
    is_running = False
```
`after_cancel(timer_id)` = **ยกเลิก**งานที่ฝากไว้ตามเลขบัตรคิว → tick ครั้งต่อไปไม่เกิด → นาฬิกาหยุด แต่ `seconds_left` ยังเก็บค่าเดิมไว้ พอกดเริ่มก็เดินต่อจากเดิม

> เปรียบเทียบ: ยื่นบัตรคิวคืนเคาน์เตอร์ = ยกเลิกคิว

#### `reset()` — ปุ่มเริ่มใหม่
หยุดนาฬิกาก่อน (เรียก `pause()` ที่เขียนไว้แล้ว ไม่ต้องเขียนซ้ำ) → กลับเป็นช่วงอ่าน → ตั้งเวลา 25:00 → แสดงผล
(ไม่ล้าง `rounds_done` เพราะรอบที่อ่านไปแล้วก็ยังนับอยู่)

### ส่วนที่ 4: สร้างหน้าต่าง

```python
label_time = tk.Label(window, font=("Arial", 64, "bold"))
```
ป้ายตัวเลขเวลา ขนาดใหญ่ 64 ตัวหนา (`bold` โบลด์ = ตัวหนา)

```python
tk.Button(frame_buttons, text="▶ เริ่ม", width=8, command=start).pack(side="left", padx=5)
```
3 ปุ่มวางเรียงจากซ้าย (`width=8` = กว้าง 8 ตัวอักษร ให้ทุกปุ่มขนาดเท่ากัน)

```python
show_time()
window.mainloop()
```
- `show_time()` = แสดง 25:00 ตั้งแต่เปิด (ไม่งั้นป้ายจะว่างจนกว่าจะกดเริ่ม)
- `mainloop()` = **event loop เริ่มทำงานตรงนี้** และจะวนรอเหตุการณ์ไปจนกว่าจะปิดหน้าต่าง

## 5. ลำดับการทำงานทั้งหมด

```
เปิดโปรแกรม → แสดง 25:00 → mainloop() เริ่มวนรอเหตุการณ์
   │
   ├─ กด "เริ่ม" → (เดินอยู่แล้ว? ออก) → ฝาก tick ไว้ 1 วินาที
   │                 │
   │                 ▼
   │              tick() ← ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┐
   │                ├─ เวลาเหลือ > 0 → ลด 1 วินาที │
   │                └─ เวลาเหลือ = 0 → เสียงเตือน    │
   │                      ├─ จบช่วงอ่าน → รอบ+1 → ตั้งพัก 5 นาที
   │                      └─ จบช่วงพัก → ตั้งอ่าน 25 นาที
   │                แสดงผล → ฝาก tick อีก 1 วินาที ─ ┘
   │
   ├─ กด "หยุด" → after_cancel ยกเลิกงานที่ฝาก → วงวนของ tick ขาด → นาฬิกาหยุด
   └─ กด "เริ่มใหม่" → หยุด → ตั้งช่วงอ่าน 25:00
```

## 6. คำถามที่อาจารย์อาจถาม + แนวตอบ

**ถาม: นาฬิกาเดินทีละวินาทีได้ยังไง?**
ตอบ: ผมใช้ `window.after(1000, tick)` ครับ หมายถึงอีก 1000 มิลลิวินาทีให้เรียกฟังก์ชัน tick ในตัว tick ก็ลดเวลาลง 1 วินาที แล้วฝากตัวเองไว้อีก 1 วินาที มันเลยวนทำงานทุกวินาทีครับ

**ถาม: ทำไมไม่ใช้ time.sleep()?**
ตอบ: เพราะ tkinter มี event loop คอยดูการกดปุ่มและวาดหน้าจอ ถ้าใช้ sleep โปรแกรมจะหลับทั้งตัว หน้าจอจะค้าง กดปุ่มหยุดไม่ได้ แต่ after แค่ฝากงานไว้ event loop ยังทำงานต่อได้ครับ

**ถาม: Event loop คืออะไร?**
ตอบ: เป็นวงวนที่โปรแกรม GUI ใช้รอเหตุการณ์ครับ เช่น การคลิก การพิมพ์ หรือเวลาที่ฝากไว้ครบ พอมีเหตุการณ์ก็เรียกฟังก์ชันที่ผูกไว้ เริ่มทำงานตอนเรียก mainloop() ครับ

**ถาม: ถ้ากดปุ่มเริ่มหลายครั้งจะเกิดอะไรขึ้น?**
ตอบ: ผมกันไว้ด้วยตัวแปร is_running ครับ ถ้าไม่กันจะมี tick หลายสายทำงานพร้อมกัน นาฬิกาจะเดินเร็วขึ้นเป็นเท่าตัว

**ถาม: ทำไมเก็บเวลาเป็นวินาที ไม่เก็บเป็นนาทีกับวินาทีแยกกัน?**
ตอบ: เก็บเป็นตัวเลขตัวเดียวแล้วลบทีละ 1 ง่ายกว่าครับ ไม่ต้องคอยเช็คว่าวินาทีถึง 0 แล้วต้องไปลดนาที ตอนแสดงผลค่อยแปลงด้วย // กับ % ครับ

**ถาม: // กับ % ต่างกันยังไง?**
ตอบ: // คือหารแล้วเอาแค่จำนวนเต็ม % คือหารแล้วเอาเศษครับ เช่น 754 วินาที // 60 ได้ 12 นาที % 60 เหลือ 34 วินาที

## 7. จุดอ่อนและวิธีพัฒนาต่อ

- **ปิดโปรแกรมแล้วจำนวนรอบหาย** → บันทึกจำนวนรอบลงไฟล์ JSON แยกตามวัน (ใช้ความรู้จาก study_planner)
- **ตั้งเวลาเองไม่ได้ ต้องแก้ในโค้ด** → เพิ่มช่องกรอกจำนวนนาที
- **หน้าต่างเด้งตอนหมดเวลาทำให้นาฬิการอ** จนกว่าจะกด OK → อาจเปลี่ยนเป็นแค่เปลี่ยนสีพื้นหลังและส่งเสียงแทน
- **ตามหลัก Pomodoro จริง** ครบ 4 รอบควรพักยาว 15–30 นาที → ใช้ `rounds_done % 4 == 0` เช็คว่าครบ 4 รอบหรือยัง

## 8. แบบฝึก (ทำเองก่อนดูโค้ด)

1. เปลี่ยนให้ช่วงพักแสดงสีพื้นหลังหน้าต่างเป็นสีเขียวอ่อน (ใบ้: `window.config(bg="lightgreen")`)
2. เพิ่มการพักยาว 15 นาทีเมื่ออ่านครบทุก 4 รอบ (ใบ้: ใช้ `%`)
3. ลองลบบรรทัด `if is_running: return` แล้วกดเริ่ม 3 ครั้ง สังเกตว่าเกิดอะไรขึ้น แล้วอธิบายว่าทำไม

# อธิบายโค้ด: โปรแกรมบัตรคำศัพท์ + แบบทดสอบ (flashcard.py)

## 1. โปรแกรมนี้ทำอะไร

- **เพิ่มคำศัพท์**: กรอกคำอังกฤษ คำอ่าน คำแปล แล้วโปรแกรมเก็บลงไฟล์ ปิดโปรแกรมแล้วข้อมูลไม่หาย
- **แบบทดสอบ**: สุ่มคำมาถาม ให้พิมพ์คำแปล โปรแกรมบอกว่าถูกหรือผิด และนับคะแนน
- **ดูคำที่ผิดบ่อย**: โปรแกรมจำว่าแต่ละคำตอบผิดไปกี่ครั้ง จะได้รู้ว่าต้องทวนคำไหน

**ทำไมทำ (เล่าให้อาจารย์ฟังได้):** ผมอ่อนภาษาอังกฤษ เลยอยากทำเครื่องมือช่วยตัวเองท่องศัพท์ และให้โปรแกรมช่วยจำแทนว่าคำไหนผมยังจำไม่ได้

## 4. อธิบายโค้ดทีละส่วน

โค้ดแบ่งเป็น 4 ส่วน เหมือนบ้าน 4 ห้อง:
1. อ่าน/บันทึกไฟล์ (ห้องเก็บของ)
2. ตัวแปรเก็บข้อมูล (สมุดจด)
3. ฟังก์ชันที่ทำงานเมื่อกดปุ่ม (คนทำงาน)
4. สร้างหน้าต่าง (หน้าร้าน)

### ส่วนหัว: นำเครื่องมือเข้ามา

```python
import tkinter as tk
from tkinter import messagebox
import random
import json
import os
```

- `import tkinter as tk` = นำ tkinter เข้ามา แล้วตั้งชื่อเล่นว่า `tk` (`as` อ่านว่า แอส = ในชื่อว่า) จะได้พิมพ์สั้นๆ
- `from tkinter import messagebox` = จาก tkinter หยิบเฉพาะ `messagebox` (เมส-เสจ-บ็อกซ์ = กล่องข้อความ) คือหน้าต่างเด้งแจ้งเตือน
- `random`, `json`, `os` = เครื่องมือสุ่ม, เครื่องมือเก็บไฟล์, เครื่องมือเช็คไฟล์

> เปรียบเทียบ: เหมือนก่อนทำกับข้าว ต้องหยิบหม้อ กระทะ มีด ออกมาวางก่อน

```python
FILE_NAME = "words.json"
```
ตั้งชื่อไฟล์เก็บคำศัพท์ไว้ที่เดียว เขียนตัวพิมพ์ใหญ่ทั้งหมดเพื่อบอกว่า "ค่านี้ไม่เปลี่ยน" (เรียกว่า constant คอน-สแตนท์ = ค่าคงที่)

### ส่วนที่ 1: อ่าน/บันทึกไฟล์

```python
def load_words():
    if os.path.exists(FILE_NAME):
        with open(FILE_NAME, "r", encoding="utf-8") as f:
            return json.load(f)
    return []
```

- `load` (โหลด) = โหลด/อ่านเข้ามา
- `os.path.exists(...)` = เช็คว่ามีไฟล์นี้อยู่ไหม (`exists` อิก-ซิสท์ = มีอยู่)
- `open(FILE_NAME, "r", ...)` = เปิดไฟล์ `"r"` มาจาก **read** (รีด) = อ่าน
- `encoding="utf-8"` (เอน-โค้ด-ดิ้ง) = บอกว่าไฟล์ใช้รหัสตัวอักษรแบบที่อ่านภาษาไทยได้ ถ้าไม่ใส่ ภาษาไทยอาจกลายเป็นตัวมั่ว
- `with ... as f` = เปิดไฟล์ ตั้งชื่อเล่นว่า `f` พอทำเสร็จ Python ปิดไฟล์ให้เอง
- `json.load(f)` = อ่านข้อมูลจากไฟล์ แปลงกลับเป็น list
- ถ้าไม่มีไฟล์ (ใช้ครั้งแรก) → `return []` = ส่ง list ว่างกลับไป

```python
def save_words():
    with open(FILE_NAME, "w", encoding="utf-8") as f:
        json.dump(words, f, ensure_ascii=False, indent=2)
```

- `save` (เซฟ) = บันทึก
- `"w"` มาจาก **write** (ไรท์) = เขียน (เขียนทับไฟล์เดิมทั้งหมด)
- `json.dump(...)` (ดัมพ์ = เทลงไป) = เทข้อมูล `words` ลงไฟล์
- `ensure_ascii=False` = ให้เก็บภาษาไทยเป็นภาษาไทยจริงๆ ไม่แปลงเป็นรหัสแปลกๆ
- `indent=2` (อิน-เดนท์ = ย่อหน้า) = จัดไฟล์ให้ย่อหน้าสวย คนเปิดอ่านได้

> เปรียบเทียบ: `load` = เปิดสมุดจดศัพท์มาอ่าน, `save` = จดลงสมุดแล้วเก็บเข้าลิ้นชัก

### ส่วนที่ 2: ตัวแปรเก็บข้อมูล

```python
words = load_words()
current_word = None
score = 0
total = 0
```

- `words` = list ของคำศัพท์ทั้งหมด ตอนเปิดโปรแกรมจะโหลดจากไฟล์ทันที
- `current_word` (เคอ-เรนท์ เวิร์ด = คำปัจจุบัน) = คำที่กำลังถามอยู่ ตอนเริ่มยังไม่มี เลยเป็น `None`
- `score` (สกอร์ = คะแนน) และ `total` (โท-ทัล = ทั้งหมด)

**หน้าตาข้อมูล 1 คำ** (เป็น dictionary):
```python
{"word": "apple", "read": "แอ๊ป-เปิ้ล", "meaning": "แอปเปิ้ล", "wrong": 0}
```
`wrong` (รอง = ผิด) คือจำนวนครั้งที่ตอบผิด เริ่มที่ 0

### ส่วนที่ 3: ฟังก์ชันที่ทำงานเมื่อกดปุ่ม

#### `add_word()` — กดปุ่ม "เพิ่มคำศัพท์"

```python
word = entry_word.get().strip()
```
`.get()` (เก็ท = เอามา) = ดึงข้อความที่พิมพ์ในช่องกรอก แล้ว `.strip()` ตัดช่องว่างหัว-ท้ายออก (เผื่อเผลอกดเว้นวรรค)

```python
if word == "" or meaning == "":
    messagebox.showwarning("แจ้งเตือน", "กรุณากรอกคำศัพท์และคำแปล")
    return
```
- `if` (อิฟ = ถ้า), `or` (ออร์ = หรือ)
- `==` คือ "เท่ากับไหม" (ต่างจาก `=` ตัวเดียวที่แปลว่า "ใส่ค่า")
- `""` = ข้อความว่าง
- แปลว่า: ถ้าคำศัพท์ว่าง **หรือ** คำแปลว่าง → เด้งเตือน แล้ว `return` จบฟังก์ชันเลย ไม่บันทึก
- นี่เรียกว่า **การตรวจสอบข้อมูล (validation วา-ลิ-เด-ชัน)** กันผู้ใช้กรอกไม่ครบ

```python
new_word = {"word": word, "read": read, "meaning": meaning, "wrong": 0}
words.append(new_word)
save_words()
```
สร้างคำใหม่เป็น dictionary → `append` ต่อท้าย list → บันทึกลงไฟล์ทันที

```python
entry_word.delete(0, tk.END)
```
`delete` (ดี-ลีท = ลบ) ตั้งแต่ตัวที่ `0` (ตัวแรก) ถึง `END` (เอนด์ = ตัวสุดท้าย) = ล้างช่องให้ว่าง

```python
label_count.config(text=f"มีคำศัพท์ทั้งหมด {len(words)} คำ")
```
- `config` (คอน-ฟิก มาจาก configure = ตั้งค่า) = เปลี่ยนข้อความบนป้าย
- `f"..."` (เอฟ-สตริง) = ข้อความที่ใส่ตัวแปรใน `{ }` ได้
- `len(...)` มาจาก **length** (เลงท์) = ความยาว → นับว่า list มีกี่ชิ้น

#### `next_question()` — กดปุ่ม "สุ่มคำถาม"

```python
global current_word
```
ตัวแปร `current_word` อยู่นอกฟังก์ชัน ถ้าจะ**แก้ค่า**ข้างในฟังก์ชัน ต้องประกาศ `global` ก่อน ไม่งั้น Python จะคิดว่าเป็นตัวแปรใหม่คนละตัว

> เปรียบเทียบ: กระดานหน้าห้องเป็นของทุกคน ถ้าจะเขียนลงกระดาน ต้องบอกก่อนว่า "ผมจะเขียนบนกระดานหน้าห้องนะ" ไม่ใช่กระดาษตัวเอง

```python
current_word = random.choice(words)
label_question.config(text=current_word["word"])
```
- `random.choice(...)` (ช้อยส์ = ตัวเลือก) = สุ่มหยิบ 1 ชิ้นจาก list
- `current_word["word"]` = ดึงค่าจาก dictionary ที่ชื่อ `"word"` (คำอังกฤษ) ไปโชว์บนจอ

#### `check_answer()` — กดปุ่ม "ตรวจคำตอบ"

```python
if answer == current_word["meaning"]:
    score = score + 1
    label_result.config(text="ถูกต้อง!", fg="green")
else:
    current_word["wrong"] = current_word["wrong"] + 1
    save_words()
    ...
```
- ถ้าคำตอบตรงกับคำแปล → คะแนน +1 ขึ้นข้อความสีเขียว (`fg` มาจาก **foreground** โฟร์-กราวนด์ = สีตัวอักษร)
- `else` (เอลส์ = ไม่อย่างนั้น) → นับว่าคำนี้ผิดเพิ่ม 1 ครั้ง แล้วบันทึกลงไฟล์ ขึ้นเฉลยสีแดง

```python
current_word = None
```
ตรวจเสร็จแล้วล้างคำปัจจุบัน **กันโกง** กดตรวจคำเดิมซ้ำๆ เพื่อปั๊มคะแนน ต้องกดสุ่มข้อใหม่ก่อน

#### `show_hard_words()` — กดปุ่ม "ดูคำที่ตอบผิดบ่อย"

```python
text = ""
for w in words:
    if w["wrong"] > 0:
        text = text + f"{w['word']} = {w['meaning']}  (ผิด {w['wrong']} ครั้ง)\n"
```
- `for w in words` (ฟอร์ = สำหรับ, อิน = ใน) = **วนลูป** หยิบคำทีละคำ ตั้งชื่อชั่วคราวว่า `w`
- ถ้าคำนั้นเคยผิด (มากกว่า 0) → เอาไปต่อท้ายข้อความ
- `\n` = ขึ้นบรรทัดใหม่ (n มาจาก **new line**)

> เปรียบเทียบ: ครูเปิดสมุดรายชื่อทีละคน ใครยังไม่ส่งงานก็จดชื่อไว้

### ส่วนที่ 4: สร้างหน้าต่าง

```python
window = tk.Tk()
window.title("Flashcard Quiz - บัตรคำศัพท์")
window.geometry("450x520")
```
- `tk.Tk()` = สร้างหน้าต่างหลัก
- `title` (ไท-เทิล) = ชื่อบนแถบหน้าต่าง
- `geometry` (จี-ออม-เมะ-ทรี = เรขาคณิต) = ขนาด กว้าง 450 x สูง 520 จุด

```python
frame_add = tk.LabelFrame(window, text="เพิ่มคำศัพท์", padx=10, pady=10)
frame_add.pack(fill="x", padx=10, pady=10)
```
- `LabelFrame` = กรอบที่มีหัวข้อ ใช้จัดกลุ่ม
- `padx`/`pady` (แพด = เว้นระยะ) = เว้นขอบแนวนอน (x) / แนวตั้ง (y)
- `.pack()` (แพ็ก = จัดใส่) = วางลงบนหน้าจอ ถ้าไม่ `pack` ของจะไม่โผล่
- `fill="x"` (ฟิล = เติมเต็ม) = ยืดเต็มความกว้าง

```python
tk.Button(frame_add, text="เพิ่มคำศัพท์", command=add_word).pack(pady=5)
```
**บรรทัดสำคัญที่สุด**: `command=add_word` = เชื่อมปุ่มกับฟังก์ชัน กดปุ่มนี้ → `add_word` ทำงาน
(สังเกต: เขียน `add_word` **ไม่มี** `()` เพราะเราส่ง "ชื่อฟังก์ชัน" ให้ปุ่มไปเรียกเองตอนกด ถ้าใส่ `()` มันจะทำงานทันทีตั้งแต่เปิดโปรแกรม)

```python
window.mainloop()
```
`mainloop` (เมน-ลูป = วงวนหลัก) = ให้หน้าต่างเปิดค้างไว้ คอยรอผู้ใช้กดปุ่ม ถ้าไม่มีบรรทัดนี้ หน้าต่างจะปิดทันที

## 5. ลำดับการทำงานทั้งหมด

```
เปิดโปรแกรม → โหลดคำศัพท์จาก words.json → แสดงหน้าต่าง → รอกดปุ่ม
   ├─ กด "เพิ่มคำศัพท์" → ตรวจว่ากรอกครบ → ต่อท้าย list → บันทึกไฟล์
   ├─ กด "สุ่มคำถาม"   → สุ่ม 1 คำ → โชว์คำอังกฤษ
   ├─ กด "ตรวจคำตอบ"   → เทียบคำตอบ → ถูก: +คะแนน / ผิด: +นับผิด, บันทึกไฟล์
   └─ กด "ดูคำที่ผิดบ่อย" → วนลูปหาคำที่ผิด > 0 → เด้งแสดง
```

## 6. คำถามที่อาจารย์อาจถาม + แนวตอบ

**ถาม: ทำไมปิดโปรแกรมแล้วคำศัพท์ไม่หาย?**
ตอบ: เพราะทุกครั้งที่เพิ่มคำหรือตอบผิด โปรแกรมบันทึกลงไฟล์ words.json ด้วย json.dump และตอนเปิดโปรแกรมใหม่ก็โหลดกลับมาด้วย json.load ครับ

**ถาม: list กับ dictionary ต่างกันยังไง?**
ตอบ: list เก็บของเรียงกันเป็นลำดับ หยิบด้วยเลขลำดับ ส่วน dictionary เก็บเป็นคู่ชื่อกับค่า หยิบด้วยชื่อ ในโปรแกรมผมใช้ list เก็บคำทั้งหมด และแต่ละคำเป็น dictionary ที่มี word, read, meaning, wrong ครับ

**ถาม: ถ้าผู้ใช้ไม่กรอกอะไรแล้วกดเพิ่มล่ะ?**
ตอบ: โปรแกรมเช็คด้วย if ว่าช่องคำศัพท์หรือคำแปลว่างไหม ถ้าว่างจะเด้งเตือนแล้ว return ออก ไม่บันทึกครับ

**ถาม: `global` ใช้ทำไม?**
ตอบ: เพราะ score, total, current_word อยู่นอกฟังก์ชัน ถ้าจะแก้ค่าในฟังก์ชันต้องบอก Python ว่าเป็นตัวแปรตัวเดียวกับข้างนอกครับ

**ถาม: จุดอ่อนของโปรแกรมนี้คืออะไร? จะพัฒนาต่อยังไง?**
ตอบ (ตอบตรงๆ ได้คะแนนดี):
- ต้องพิมพ์คำแปลตรงเป๊ะถึงจะถูก ถ้าคำแปลมีหลายแบบจะนับผิด → อาจเปลี่ยนเป็นแบบเลือกตอบ 4 ข้อ
- สุ่มแบบเท่ากันทุกคำ → อยากให้คำที่ผิดบ่อยถูกสุ่มมาถามบ่อยขึ้น
- ลบหรือแก้คำที่พิมพ์ผิดไม่ได้ → เพิ่มปุ่มลบ/แก้ไข

## 3. สูตร GPA (ต้องเข้าใจก่อนอ่านโค้ด)

**GPA** ย่อมาจาก **G**rade **P**oint **A**verage (เกรด พอยต์ แอฟ-เวอ-เรจ = ค่าเฉลี่ยแต้มเกรด)

```
GPA = ผลรวมของ (หน่วยกิต × เกรด) ÷ ผลรวมของหน่วยกิต
```

**ตัวอย่าง**

| วิชา | หน่วยกิต | เกรด | หน่วยกิต × เกรด |
|---|---|---|---|
| คณิต | 1.5 | 4 | 6.0 |
| อังกฤษ | 1.0 | 3 | 3.0 |
| **รวม** | **2.5** | | **9.0** |

GPA = 9.0 ÷ 2.5 = **3.60**

> 💡 ทำไมไม่เอาเกรดมาบวกกันแล้วหาร 2 (ได้ 3.5)? เพราะวิชาที่หน่วยกิตเยอะเรียนมากกว่า จึงควรมี "น้ำหนัก" มากกว่า เรียกว่า **weighted average** (เว-ทิด แอฟ-เวอ-เรจ = ค่าเฉลี่ยถ่วงน้ำหนัก)

## 5. อธิบายโค้ดทีละส่วน

### 5.1 ข้อมูลตั้งต้น

```python
GRADES = ["4", "3.5", "3", "2.5", "2", "1.5", "1", "0"]
CREDITS = ["0.5", "1", "1.5", "2", "3"]
subjects = []
```

- `GRADES` และ `CREDITS` เป็น list ของ **ตัวเลือก** ในเมนู เก็บเป็นข้อความ (มีเครื่องหมาย `" "`) เพราะเมนูของ tkinter แสดงเป็นข้อความ
- ให้ **เลือก** แทน **พิมพ์** เพราะผู้ใช้จะพิมพ์ผิดไม่ได้เลย (เช่น พิมพ์เกรด 5) จึงไม่ต้องเขียนโค้ดตรวจเพิ่ม
- `subjects = []` คือ list ว่าง เป็น **ที่เก็บข้อมูลหลัก** ของโปรแกรม ทุกวิชาที่เพิ่มจะถูกต่อท้ายที่นี่ เช่น
  ```python
  [("คณิต", 1.5, 4.0), ("อังกฤษ", 1.0, 3.0)]
  ```
  แต่ละวิชาเป็น **tuple** (ทู-เพิล = กลุ่มข้อมูลที่จับรวมกัน) 3 ช่อง: ชื่อ, หน่วยกิต, เกรด

### 5.2 ฟังก์ชัน `calculate_gpa` (หัวใจของโปรแกรม)

```python
def calculate_gpa(subject_list):
    total_points = 0
    total_credits = 0
    for name, credit, grade in subject_list:
        total_points = total_points + credit * grade
        total_credits = total_credits + credit
    if total_credits == 0:
        return 0
    return total_points / total_credits
```

- เริ่มจากตั้ง "กระปุกสะสม" 2 ใบเป็น 0: `total_points` (ผลรวมแต้ม) และ `total_credits` (ผลรวมหน่วยกิต)
- `for name, credit, grade in subject_list:` วนทีละวิชา และ **แกะ tuple** ออกเป็น 3 ตัวแปรในคราวเดียว
- `total_points = total_points + credit * grade` แปลว่า "เอาของเดิมในกระปุก บวกแต้มของวิชานี้ แล้วเก็บกลับเข้ากระปุก" (`*` คือคูณ)
- เรียกรูปแบบนี้ว่า **accumulator** (แอ็ก-คิว-มิว-เล-เตอร์ = ตัวสะสม) ใช้บ่อยมากในการเขียนโปรแกรม
- `if total_credits == 0:` (`==` แปลว่า "เท่ากับไหม" ส่วน `=` ตัวเดียวแปลว่า "ใส่ค่า") ถ้ายังไม่มีวิชาเลย ห้ามหาร เพราะ **หารด้วย 0 จะทำให้โปรแกรมพัง** (ZeroDivisionError ซี-โร่ ดิ-วิ-ชัน เออ-เรอร์)
- `/` คือหารปกติ ได้ทศนิยม (ต่างจาก `//` ในโปรเจกต์เงินทอนที่เอาแค่จำนวนเต็ม)

> 💡 ฟังก์ชันนี้ **ไม่ยุ่งกับหน้าจอเลย** รับ list เข้ามา คืนตัวเลขออกไป จึงทดสอบแยกได้ง่าย และเอาไปใช้กับโปรแกรมอื่นได้

### 5.3 ฟังก์ชัน `refresh_screen` (วาดหน้าจอใหม่)

```python
def refresh_screen():
    subject_listbox.delete(0, tk.END)
    for name, credit, grade in subjects:
        subject_listbox.insert(tk.END, f"{name}   |   {credit} หน่วยกิต   |   เกรด {grade}")

    gpa = calculate_gpa(subjects)
    gpa_label.config(text=f"GPA = {gpa:.2f}")
```

- แนวคิด: **ลบกล่องทิ้งทั้งหมด แล้ววาดใหม่จาก `subjects`** ทำแบบนี้ทุกครั้งที่ข้อมูลเปลี่ยน จึงไม่มีทางที่หน้าจอกับข้อมูลจริงจะไม่ตรงกัน
- `insert(tk.END, ...)` (อิน-เสิร์ต = แทรก) เพิ่มบรรทัดต่อท้ายกล่อง
- `{gpa:.2f}` เป็นการจัดรูปแบบตัวเลข: `.2` = ทศนิยม 2 ตำแหน่ง, `f` = **f**loat เช่น 3.6 แสดงเป็น `3.60`

### 5.4 ฟังก์ชัน `on_add` (กดเพิ่มวิชา)

```python
def on_add(event=None):
    name = name_entry.get().strip()
    if name == "":
        message_label.config(text="กรุณาพิมพ์ชื่อวิชาก่อน", fg="red")
        return

    credit = float(credit_var.get())
    grade = float(grade_var.get())
    subjects.append((name, credit, grade))

    name_entry.delete(0, tk.END)
    message_label.config(text=f"เพิ่มวิชา {name} แล้ว ✔", fg="green")
    refresh_screen()
```

- ตรวจก่อนว่าพิมพ์ชื่อวิชาหรือยัง (`""` คือข้อความว่าง)
- `credit_var.get()` ได้ข้อความ เช่น `"1.5"` แล้ว `float(...)` แปลงเป็นตัวเลขทศนิยม `1.5` เพื่อเอาไปคูณได้
- `subjects.append(...)` ต่อวิชาใหม่ท้าย list
- ล้างช่องชื่อวิชา บอกว่าเพิ่มสำเร็จ แล้วเรียก `refresh_screen()` ให้หน้าจออัปเดต

### 5.5 ฟังก์ชัน `on_delete` (ลบวิชาที่เลือก)

```python
def on_delete():
    selected = subject_listbox.curselection()
    if len(selected) == 0:
        message_label.config(text="คลิกเลือกวิชาที่จะลบก่อน", fg="red")
        return
    index = selected[0]
    removed = subjects.pop(index)
    message_label.config(text=f"ลบวิชา {removed[0]} แล้ว", fg="black")
    refresh_screen()
```

- `curselection()` มาจาก **cur**rent **selection** (เคอ-เรนต์ ซี-เล็ก-ชัน = สิ่งที่เลือกอยู่ตอนนี้) คืนค่าลำดับบรรทัดที่ถูกคลิก เช่น `(2,)`
- `len(...)` มาจาก **len**gth (เลงท์ = ความยาว) ถ้าเป็น 0 แปลว่ายังไม่ได้เลือก
- `selected[0]` หยิบตัวแรก **คอมพิวเตอร์นับจาก 0** บรรทัดแรกคือ 0 บรรทัดที่สองคือ 1
- `subjects.pop(index)` (ป็อป = ดึงออก) ดึงวิชาตำแหน่งนั้นออกจาก list และส่งคืนวิชานั้นมาให้ จึงเอา `removed[0]` (ชื่อวิชา) ไปแสดงได้
- ลำดับในกล่องตรงกับลำดับใน `subjects` เสมอ เพราะ `refresh_screen` วาดจาก `subjects` ตามลำดับ จึงใช้ index เดียวกันได้

### 5.6 ส่วน GUI ที่ใหม่ในโปรเจกต์นี้

```python
tk.Label(input_frame, text="ชื่อวิชา").grid(row=0, column=0)
name_entry.grid(row=1, column=0, padx=5)
```

- `.grid()` (กริด = ตาราง) วางชิ้นส่วนเป็น **แถว** (row โร) และ **คอลัมน์** (column คอ-ลัม) เหมือนตาราง Excel เหมาะกับฟอร์มที่มีหัวข้อด้านบน ช่องกรอกด้านล่าง
  - ⚠️ ในกรอบ (Frame) เดียวกัน ห้ามใช้ `pack` ปนกับ `grid` จึงสร้าง `input_frame` แยกไว้ใช้ grid ส่วนหน้าต่างหลักใช้ pack

```python
credit_var = tk.StringVar(value="1")
tk.OptionMenu(input_frame, credit_var, *CREDITS).grid(row=1, column=1, padx=5)
```

- `StringVar` (สตริง-วาร์ = ตัวแปรข้อความแบบพิเศษของ tkinter) เป็นกล่องที่ผูกกับเมนู เมื่อผู้ใช้เลือก ค่าในกล่องนี้จะเปลี่ยนตาม เราอ่านด้วย `.get()`
  - `value="1"` ค่าเริ่มต้นตอนเปิดโปรแกรม
- `OptionMenu` (ออป-ชัน เมน-นู = เมนูตัวเลือก) ปุ่มที่กดแล้วมีรายการให้เลือก
- `*CREDITS` เครื่องหมาย `*` แปลว่า **"แตกรายการออกมาเป็นชิ้นๆ"** คือเหมือนพิมพ์ `"0.5", "1", "1.5", "2", "3"` เองทีละตัว

```python
subject_listbox = tk.Listbox(root, width=45, height=10)
```

- `Listbox` (ลิสต์-บ็อกซ์ = กล่องรายการ) แสดงหลายบรรทัด คลิกเลือกได้ `height=10` แสดง 10 บรรทัด

## 6. ลำดับการทำงานเมื่อกด "เพิ่มวิชา"

1. ผู้ใช้พิมพ์ "คณิต" เลือก 1.5 หน่วยกิต เกรด 4 แล้วกดปุ่ม
2. `on_add` ตรวจชื่อ → แปลงเป็นตัวเลข → `subjects` กลายเป็น `[("คณิต", 1.5, 4.0)]`
3. `refresh_screen` ลบกล่อง → ใส่ "คณิต | 1.5 หน่วยกิต | เกรด 4.0" → เรียก `calculate_gpa`
4. `calculate_gpa` คืน 6.0 ÷ 1.5 = 4.0 → ป้ายแสดง `GPA = 4.00`

## 7. คำถามที่กรรมการอาจถาม และแนวตอบ

**Q1: ทำไมไม่เอาเกรดทุกวิชามาเฉลี่ยตรงๆ?**
> เพราะแต่ละวิชามีหน่วยกิตไม่เท่ากัน วิชาที่หน่วยกิตเยอะควรมีผลมากกว่า จึงใช้ค่าเฉลี่ยถ่วงน้ำหนัก คือคูณเกรดด้วยหน่วยกิตก่อนแล้วหารด้วยหน่วยกิตรวมครับ

**Q2: ถ้ายังไม่มีวิชาเลยแล้วคำนวณ จะเกิดอะไรขึ้น?**
> หน่วยกิตรวมเป็น 0 ซึ่งหารไม่ได้และจะทำให้โปรแกรมพัง ผมเลยเช็กก่อนว่าถ้าเป็น 0 ให้คืนค่า 0 ไปเลยครับ

**Q3: ทำไมให้เลือกเกรดจากเมนู ไม่ให้พิมพ์?**
> ป้องกันการกรอกผิดตั้งแต่ต้น เช่น เกรด 5 หรือพิมพ์ตัวหนังสือ ทำให้โค้ดง่ายขึ้นและผู้ใช้ใช้งานง่ายขึ้นครับ

**Q4: ตอนลบวิชา รู้ได้ยังไงว่าต้องลบตัวไหนใน list?**
> กล่องรายการแสดงตามลำดับเดียวกับ list เสมอ เพราะผมวาดใหม่จาก list ทุกครั้ง เลยเอาลำดับที่ผู้ใช้คลิกมา `pop` ออกจาก list ได้ตรงตัวครับ

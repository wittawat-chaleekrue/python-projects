# อธิบายโค้ด: โปรแกรมเลือกตั้งประธานนักเรียน (student_vote.py)

## 1. โปรแกรมนี้ทำอะไร

- นักเรียน **กรอกรหัส 5 หลัก** → **เลือกผู้สมัคร 1 ช่อง** (มีช่อง "งดออกเสียง" ด้วย) → กด **ลงคะแนน**
- ถ้ารหัสนั้น **โหวตไปแล้ว** โปรแกรมจะไม่ยอมให้โหวตซ้ำ
- หลังโหวต หน้าจอจะล้างทันที **ไม่โชว์ว่าเลือกใคร** (เพราะเป็นการลงคะแนนลับ)
- กด **"ปิดหีบ นับคะแนน"** → วาด **กราฟแท่ง** พร้อมเปอร์เซ็นต์ และประกาศผู้ชนะ (ถ้าคะแนนเท่ากันจะบอกว่าเสมอ)

**ทำไมทำ (เล่าให้อาจารย์ฟังได้):** ทุกปีโรงเรียนมีเลือกตั้งประธานนักเรียน ใช้บัตรกระดาษแล้วต้องนั่งนับนาน และมีปัญหาคนกาซ้ำ ผมเลยทำระบบที่ **กันโหวตซ้ำได้อัตโนมัติ** และนับคะแนนเสร็จในพริบตา โดยใช้โครงสร้างข้อมูล **set** ซึ่งเหมาะกับงาน "เช็คว่าเคยมีหรือยัง" ที่สุด

## 4. อธิบายโค้ดทีละส่วน

### หน้าตาข้อมูล

```python
candidates = ["เบอร์ 1 พรรคใส่ใจ", "เบอร์ 2 พรรคก้าวหน้า", "เบอร์ 3 พรรครักษ์โลก", "งดออกเสียง"]

scores = {}
for name in candidates:
    scores[name] = 0
```
- `candidates` เป็น **list** เก็บชื่อผู้สมัครเรียงตามเบอร์
- `scores` เป็น **dict** (ดิก = พจนานุกรม) จับคู่ "ชื่อ → คะแนน" วนลูปตั้งให้ทุกคนเริ่มที่ 0 ได้ผลแบบนี้:
  `{"เบอร์ 1 พรรคใส่ใจ": 0, "เบอร์ 2 พรรคก้าวหน้า": 0, ...}`
- **เปรียบเทียบ:** dict เหมือนกระดานนับคะแนนหน้าห้อง ที่มีชื่อผู้สมัครเขียนไว้ แล้วขีดคะแนนข้างชื่อ

```python
voted_ids = set()
```
**ใหม่! `set` (เซ็ต)** = กลุ่มข้อมูลที่ **ไม่มีทางมีค่าซ้ำ** และ **ไม่สนลำดับ**
- เปรียบเทียบ: เหมือน **สมุดลงชื่อมาใช้สิทธิ์** หน้าคูหา ใครลงชื่อแล้วจะลงซ้ำไม่ได้
- ทำไมเขียน `set()` ไม่เขียน `{}` → เพราะ `{}` เปล่า ๆ Python ถือว่าเป็น **dict ว่าง** ถ้าอยากได้ set ว่างต้องเขียน `set()`

**ลองใน Terminal (พิมพ์ `python3` ก่อน):**
```python
>>> s = set()
>>> s.add("11111")
>>> s.add("11111")      # เพิ่มซ้ำ
>>> s
{'11111'}               # ยังมีแค่ตัวเดียว!
>>> "11111" in s
True
```

### ส่วนที่ 1: `vote()` — ลงคะแนน ⭐

```python
if len(student_id) != 5 or not student_id.isdigit():
```
- `len()` (เลน มาจาก length = ความยาว) นับจำนวนตัวอักษร
- `!=` แปลว่า "ไม่เท่ากับ"
- `.isdigit()` ตอบ True ถ้า **ทุกตัว** เป็นเลข 0–9
- `not` (น็อท = ไม่) กลับค่า True ↔ False
- รวมแปลว่า "ถ้ายาวไม่ใช่ 5 **หรือ** ไม่ใช่ตัวเลขล้วน → เตือนแล้วหยุด"

```python
if student_id in voted_ids:
    messagebox.showerror("โหวตซ้ำ!", ...)
    return
```
**หัวใจของโปรแกรม** ถามว่า "รหัสนี้อยู่ในสมุดลงชื่อแล้วหรือยัง" ถ้าอยู่แล้ว → ไม่ให้โหวต
- `return` (รี-เทิร์น = กลับ) ตรงนี้ใช้ **ออกจากฟังก์ชันทันที** บรรทัดข้างล่างจะไม่ทำงาน

```python
voted_ids.add(student_id)
scores[choice] = scores[choice] + 1
```
- จดรหัสลง set
- เปิด dict ไปที่ชื่อผู้สมัครที่เลือก แล้วบวก 1

```python
entry_id.delete(0, tk.END)
selected.set("")
```
ล้างช่องรหัส และยกเลิกการติ๊ก เพื่อให้คนต่อไป **ไม่เห็นว่าคนก่อนเลือกใคร** (การลงคะแนนลับ)

### ส่วนที่ 2: `count_votes()` — วาดกราฟแท่ง ⭐

```python
max_score = max(scores.values())
```
- `scores.values()` (แวล-ลิว = ค่า) ดึงเฉพาะตัวเลขคะแนนออกมา เช่น `[2, 1, 0, 1]`
- `max()` หาตัวที่มากที่สุด → `2`

```python
height = score / max_score * max_height
```
**บัญญัติไตรยางศ์** ที่เรียนตอน ม.ต้น: คะแนนสูงสุดให้สูง 140 จุด คนอื่นสูงตามสัดส่วน
- ตัวอย่าง: max = 2, คนที่ได้ 1 คะแนน → 1 / 2 × 140 = **70 จุด** (ครึ่งหนึ่งของแท่งสูงสุด)

```python
x = 30 + i * 105
canvas.create_rectangle(x, base_y - height, x + bar_width, base_y, fill=colors[i])
```
- แท่งที่ 0 เริ่มที่ x=30, แท่งที่ 1 เริ่มที่ 135, แท่งที่ 2 เริ่มที่ 240 … (ขยับทีละ 105)
- `create_rectangle(x1, y1, x2, y2)` วาดสี่เหลี่ยมจาก **มุมซ้ายบน** ไป **มุมขวาล่าง**
- ⚠️ บน Canvas **แกน y ยิ่งมากยิ่งอยู่ล่าง** (กลับหัวกับกราฟในวิชาคณิต) ยอดแท่งจึงอยู่ที่ `base_y - height`

```python
percent = score * 100 / total
text=f"{score} ({percent:.0f}%)"
```
- `:.0f` แปลว่า "แสดงทศนิยม 0 ตำแหน่ง" → 66.666 กลายเป็น `67`

#### หาผู้ชนะ (รองรับคะแนนเท่ากัน)
```python
for name in candidates[:-1]:
    if scores[name] > best:
        best = scores[name]
        winners = [name]
    elif scores[name] == best and best > 0:
        winners.append(name)
```
- `[:-1]` = ทุกตัว **ยกเว้นตัวสุดท้าย** (ตัด "งดออกเสียง" ออก เพราะงดออกเสียงชนะไม่ได้)
- เจอคนคะแนนมากกว่า → เขาเป็นผู้ชนะคนเดียว (สร้างลิสต์ใหม่)
- เจอคนคะแนน **เท่ากับ** ผู้ชนะ → เพิ่มเข้าลิสต์ (เสมอ)
- จบแล้วนับว่า `winners` มีกี่คน: 0 = ไม่มีผู้ชนะ, 1 = ชนะเด็ดขาด, มากกว่า 1 = เสมอ
- `", ".join(winners)` เอาชื่อในลิสต์มาต่อกันคั่นด้วยลูกน้ำ

### ส่วนที่ 3: สร้างหน้าต่าง

```python
selected = tk.StringVar(value="")
for name in candidates:
    tk.Radiobutton(frame_vote, text=name, variable=selected, value=name).pack(anchor="w")
```
- Radiobutton ทุกปุ่ม **ผูกกับตัวแปรเดียวกัน** (`variable=selected`) จึงเลือกได้แค่ทีละปุ่ม
- กดปุ่มไหน `selected` จะมีค่าเท่ากับ `value` ของปุ่มนั้น → เราใช้ `selected.get()` อ่านค่า
- `anchor="w"` (แอง-เคอร์ = สมอเรือ, w = west ทิศตะวันตก) = ชิดซ้าย

## 5. ลำดับการทำงานทั้งหมด

```
เปิดโปรแกรม → ตั้งคะแนนทุกคน = 0 → set ว่าง → รอเหตุการณ์
   ├─ "ลงคะแนน" → รหัสเป็นเลข 5 หลัก?   ไม่ → เตือน
   │            → รหัสอยู่ใน set แล้ว?   ใช่ → "โหวตซ้ำ!"
   │            → เลือกผู้สมัครหรือยัง?  ไม่ → เตือน
   │            → add รหัสลง set → คะแนน +1 → ล้างหน้าจอ
   └─ "ปิดหีบ นับคะแนน" → ยังไม่มีคนโหวต? เตือน
                        → หาคะแนนสูงสุด → วาดแท่งทีละช่อง (สูงตามสัดส่วน)
                        → หาผู้ชนะ (ไม่นับงดออกเสียง) → ชนะ / เสมอ / ไม่มี
```

## 6. คำถามที่อาจารย์อาจถาม + แนวตอบ

**ถาม: ทำไมใช้ set ไม่ใช้ list เก็บรหัสที่โหวตแล้ว?**
ตอบ: มี 2 เหตุผลครับ ข้อแรก set ไม่เก็บค่าซ้ำ ซึ่งตรงกับงานนี้พอดี ข้อสอง การเช็ค `in` ของ set เร็วมาก ไม่ว่าจะมีข้อมูลกี่ตัวก็ใช้เวลาประมาณเท่าเดิม (O(1)) ส่วน list ต้องไล่ดูทีละตัวแบบ Linear Search (O(n)) ถ้านักเรียน 2,000 คน list อาจต้องดูถึง 2,000 ครั้ง

**ถาม: set เช็คได้เร็วขนาดนั้นได้ยังไง?**
ตอบ: set ใช้เทคนิคที่เรียกว่า **Hash (แฮช)** ครับ คือเอาข้อมูลไปคำนวณเป็นตัวเลขที่บอกตำแหน่งที่เก็บ เวลาหาก็คำนวณซ้ำแล้วไปดูตำแหน่งนั้นได้เลย เหมือนตู้ล็อกเกอร์ที่เลขตู้คำนวณจากรหัสนักเรียน ไม่ต้องเปิดทุกตู้

**ถาม: dict กับ set ต่างกันยังไง?**
ตอบ: dict เก็บเป็น **คู่** คีย์ → ค่า เช่น ชื่อ → คะแนน ส่วน set เก็บแค่ **คีย์อย่างเดียว** ไม่มีค่าคู่ ทั้งคู่ใช้ Hash เหมือนกัน และคีย์ห้ามซ้ำเหมือนกันครับ

**ถาม: ถ้าคะแนนเท่ากันโปรแกรมทำยังไง?**
ตอบ: ผมเก็บผู้ชนะเป็นลิสต์ ถ้าเจอคนคะแนนเท่ากับสูงสุดก็เพิ่มเข้าลิสต์ ถ้าลิสต์มีมากกว่า 1 คนจะแสดงว่าเสมอครับ

**ถาม: ระบบนี้โกงได้ไหม?**
ตอบ: ได้ครับ เพราะยังไม่ได้ตรวจว่ารหัสมีอยู่จริงในโรงเรียน ใครพิมพ์เลขมั่ว 5 หลักก็โหวตได้ วิธีแก้คือโหลดรายชื่อนักเรียนจริงเข้า set อีกอันแล้วเช็คว่ารหัสอยู่ในนั้นไหม

**ถาม: ทำไมยอดแท่งกราฟคำนวณเป็น `base_y - height`?**
ตอบ: เพราะบน Canvas จุด (0,0) อยู่มุมซ้ายบน แกน y ยิ่งมากยิ่งลงล่าง แท่งที่สูงขึ้นจึงต้องลบออกจากเส้นฐานครับ

## 7. จุดอ่อนและวิธีพัฒนาต่อ

- **ไม่ตรวจว่ารหัสมีจริง** → โหลดรายชื่อนักเรียนจริงจากไฟล์ แล้วเช็คก่อนโหวต
- **ปิดโปรแกรมแล้วคะแนนหาย** → บันทึก `scores` และ `voted_ids` ลงไฟล์ JSON (ต้องแปลง set เป็น list ก่อน เพราะ JSON ไม่รู้จัก set)
- **ใครก็กดนับคะแนนได้ระหว่างเลือกตั้ง** → ใส่รหัสผ่านกรรมการก่อนดูผล
- **ชื่อผู้สมัครเขียนตายตัวในโค้ด** → ทำหน้าเพิ่มผู้สมัคร
- **คนเห็นหน้าจอตอนกดได้** → ในงานจริงต้องจัดคูหาให้มิดชิด

# อธิบายโค้ด: โปรแกรมจัดอันดับคะแนนนักเรียน (score_ranking.py)

## 1. โปรแกรมนี้ทำอะไร

- **กรอกชื่อ + คะแนน** ของนักเรียนทีละคน (คะแนน 0–100)
- กด **"จัดอันดับ"** → โปรแกรมเรียงคะแนน**จากมากไปน้อย** แล้วขึ้นอันดับ 1, 2, 3, ...
- บอกว่าการเรียงครั้งนี้ต้อง **สลับไปกี่ครั้ง**
- กด **"ดูลำดับที่กรอก"** เพื่อดูลำดับเดิมก่อนเรียง เทียบกันได้
- **ลบทั้งหมด** เพื่อเริ่มกรอกห้องใหม่

**จุดเด่น:** การเรียงข้อมูลใช้ **Bubble Sort ที่เขียนเอง** ไม่ได้ใช้คำสั่ง `sort()` สำเร็จรูปของ Python เพราะผมอยากเข้าใจว่าคอมพิวเตอร์เรียงข้อมูลยังไงจริง ๆ

**ทำไมทำ (เล่าให้อาจารย์ฟังได้):** เวลาครูประกาศผลสอบหรือคัดตัวแทนแข่งขัน ต้องเรียงคะแนนนักเรียนทั้งห้อง ถ้าทำมือจะช้าและผิดง่าย ผมเลยทำโปรแกรมที่กรอกคะแนนแล้วจัดอันดับให้ทันที และใช้โอกาสนี้ฝึกเขียนอัลกอริทึมการเรียงข้อมูล ซึ่งเป็นพื้นฐานสำคัญของวิทยาการคอมพิวเตอร์

### ส่วนที่ 1: `bubble_sort()` — หัวใจของโปรแกรม ⭐

#### ไอเดียของ Bubble Sort (อ่านก่อนดูโค้ด)

**กฎมีข้อเดียว:** มองทีละ **2 คนที่ยืนติดกัน** ถ้าคนซ้ายคะแนน**น้อยกว่า**คนขวา → **สลับที่กัน** แล้วขยับไปมองคู่ถัดไป ทำแบบนี้จนสุดแถว = 1 รอบ แล้วทำซ้ำหลาย ๆ รอบจนเรียงครบ

> เปรียบเทียบ: ครูให้นักเรียนเข้าแถวเรียงตามความสูงจากสูงไปเตี้ย ครูเดินจากหัวแถว ดูทีละ 2 คนที่ยืนติดกัน ถ้าคนหน้าเตี้ยกว่าคนหลังก็ให้สลับที่ เดินจนสุดแถวแล้วเริ่มใหม่จากหัวแถว ทำไปเรื่อย ๆ จนไม่มีใครต้องสลับ

**ทำไมชื่อ "ฟองอากาศ"?** เพราะในแต่ละรอบ ตัวที่น้อยที่สุดจะถูกสลับไปเรื่อย ๆ จน**ลอยไปอยู่ท้ายแถว**ทีละช่อง เหมือนฟองอากาศที่ค่อย ๆ ลอยขึ้นผิวน้ำ

#### ลองทำด้วยมือ: เอ 60, บี 85, ซี 70, ดี 95

**รอบที่ 1** (เทียบ 3 คู่)
```
[60, 85, 70, 95]   60 กับ 85 → 60 น้อยกว่า สลับ!
[85, 60, 70, 95]   60 กับ 70 → สลับ!
[85, 70, 60, 95]   60 กับ 95 → สลับ!
[85, 70, 95, 60]   ← 60 (น้อยสุด) ลอยไปอยู่ท้ายแถวแล้ว ✅ ตัวนี้อยู่ถูกที่แล้ว
```
**รอบที่ 2** (เทียบแค่ 2 คู่ เพราะตัวท้ายเข้าที่แล้ว)
```
[85, 70, 95, 60]   85 กับ 70 → 85 มากกว่า ไม่ต้องสลับ
[85, 70, 95, 60]   70 กับ 95 → สลับ!
[85, 95, 70, 60]   ← 70 เข้าที่แล้ว ✅
```
**รอบที่ 3** (เทียบแค่ 1 คู่)
```
[85, 95, 70, 60]   85 กับ 95 → สลับ!
[95, 85, 70, 60]   ← เรียงเสร็จ! 🎉
```
รวมสลับ 3 + 1 + 1 = **5 ครั้ง** และเทียบไป 3 + 2 + 1 = **6 ครั้ง**

#### ทีนี้มาดูโค้ด

```python
def bubble_sort(data):
    items = data.copy()
```
`.copy()` = ทำ**สำเนา** list ก่อนเรียง ถ้าไม่ก๊อป การสลับจะไปเปลี่ยน list `students` ตัวจริงด้วย แล้วปุ่ม "ดูลำดับที่กรอก" จะดูลำดับเดิมไม่ได้อีก

> เปรียบเทียบ: ถ่ายเอกสารใบรายชื่อมาขีดเขียน ใบจริงจะได้ไม่เลอะ

```python
    n = len(items)
    swaps = 0
```
`n` = จำนวนนักเรียน, `swaps` = ตัวนับจำนวนครั้งที่สลับ

```python
    for i in range(n - 1):
```
**ลูปนอก = จำนวนรอบ** นักเรียน 4 คนทำ 3 รอบ (`range(3)` = 0, 1, 2)
**ทำไม n-1 รอบ?** แต่ละรอบจะมี 1 คนเข้าที่ พอเหลือคนสุดท้ายคนเดียวก็ไม่มีใครให้เทียบแล้ว มันจึงอยู่ถูกที่เองโดยอัตโนมัติ

```python
        for j in range(n - 1 - i):
```
**ลูปใน = เดินเทียบทีละคู่** (นี่คือ **loop ซ้อน loop** = ลูปในทำงานจนครบทุกครั้งที่ลูปนอกเดิน 1 ก้าว)
- `j` คือตำแหน่งคนซ้ายของคู่ที่กำลังเทียบ (เทียบ `j` กับ `j + 1`)
- ทำไม `n - 1`? ถ้ามี 4 คน มีคู่ติดกัน 3 คู่ (0-1, 1-2, 2-3) ถ้าให้ j ไปถึง 3 จะไปหยิบตำแหน่งที่ 4 ซึ่งไม่มี → error
- ทำไม `- i`? ท้ายแถวมีคนที่เข้าที่แล้ว `i` คน ไม่ต้องเทียบซ้ำ (รอบ 1 เทียบ 3 คู่ → รอบ 2 เทียบ 2 คู่ → รอบ 3 เทียบ 1 คู่ ตรงกับที่ทำมือไว้)

```python
            if items[j]["score"] < items[j + 1]["score"]:
```
ถ้าคะแนนคนซ้าย **น้อยกว่า** คนขวา → ผิดลำดับ (เราต้องการมากไปน้อย)
💡 ถ้าอยากเรียง**น้อยไปมาก** เปลี่ยน `<` เป็น `>` แค่ตัวเดียว

```python
                items[j], items[j + 1] = items[j + 1], items[j]
                swaps = swaps + 1
```
**การสลับ (swap)** ใน Python เขียนบรรทัดเดียวได้ แปลว่า "ให้ช่อง j รับค่าของช่อง j+1 **และพร้อมกัน** ให้ช่อง j+1 รับค่าของช่อง j"
Python จะหยิบค่าทางขวาทั้ง 2 ตัวขึ้นมาถือไว้ก่อน แล้วค่อยวางลงทางซ้าย ค่าจึงไม่หาย

> ถ้าเขียนแบบนี้จะ**ผิด**:
> ```python
> items[j] = items[j + 1]     # ช่อง j ถูกทับ ค่าเดิมหายไปแล้ว!
> items[j + 1] = items[j]     # ได้ค่าเดิมของ j+1 กลับมา = ทั้ง 2 ช่องเหมือนกัน
> ```
> ภาษาอื่นต้องใช้ตัวแปรพักไว้ก่อน (เหมือนสลับน้ำในแก้ว 2 ใบ ต้องมีแก้วเปล่าใบที่ 3)

```python
    return items, swaps
```
คืนค่า **2 อย่างพร้อมกัน** คือ list ที่เรียงแล้ว และจำนวนครั้งที่สลับ ตอนเรียกใช้ก็รับ 2 ตัวได้: `ranked, swaps = bubble_sort(students)`

## 6. คำถามที่อาจารย์อาจถาม + แนวตอบ

**ถาม: อธิบาย Bubble Sort หน่อย**
ตอบ: เทียบข้อมูลทีละคู่ที่อยู่ติดกัน ถ้าผิดลำดับก็สลับ ทำจนสุดแถวเป็น 1 รอบ แต่ละรอบจะมีตัวหนึ่งเข้าไปอยู่ท้ายแถวถูกที่ ทำ n-1 รอบก็เรียงครบครับ ที่ชื่อ Bubble เพราะค่าจะค่อย ๆ ลอยไปท้ายแถวเหมือนฟองอากาศ

**ถาม: ทำไมไม่ใช้ sort() ของ Python?**
ตอบ: ใช้ได้และเร็วกว่าด้วยครับ แต่ผมอยากเข้าใจว่าการเรียงข้อมูลทำงานยังไงข้างใน เลยเขียนอัลกอริทึมเอง ถ้าใช้งานจริงผมจะใช้ sort() ครับ

**ถาม: ถ้ามีนักเรียน n คน ต้องเทียบกี่ครั้ง?**
ตอบ: (n-1) + (n-2) + ... + 1 ครั้งครับ เช่น 4 คนเทียบ 3+2+1 = 6 ครั้ง ถ้า 40 คนเทียบ 780 ครั้ง ถ้าคนเพิ่มเป็น 2 เท่า จำนวนครั้งที่เทียบจะเพิ่มประมาณ 4 เท่า เพราะโตตาม n คูณ n ครับ (ในวิชา CS เขียนว่า **O(n²)** อ่านว่า "โอ-เอ็น-สแควร์" ใช้บอกว่าอัลกอริทึมช้าลงแค่ไหนเมื่อข้อมูลเยอะขึ้น)

**ถาม: ทำไมลูปในต้องเป็น n - 1 - i?**
ตอบ: ลบ 1 เพราะเทียบตำแหน่ง j กับ j+1 ถ้าไม่ลบจะหยิบเกินท้าย list แล้ว error ส่วนลบ i เพราะทุกรอบที่ผ่านไป ท้ายแถวจะมีตัวที่เข้าที่แล้วเพิ่มขึ้น 1 ตัว ไม่ต้องเทียบซ้ำครับ

**ถาม: สลับค่าใน Python บรรทัดเดียวได้ยังไง?**
ตอบ: Python จะหยิบค่าทางขวาทั้งคู่ขึ้นมาก่อน แล้วค่อยวางลงทางซ้ายพร้อมกัน ค่าเลยไม่ทับกันครับ ถ้าเขียนแยก 2 บรรทัดค่าแรกจะหายไป

**ถาม: ทำไมต้อง .copy() ก่อนเรียง?**
ตอบ: เพื่อไม่ให้ไปเปลี่ยนลำดับข้อมูลจริงครับ ผมยังอยากเก็บลำดับที่กรอกไว้ให้ดูได้

## 7. จุดอ่อนและวิธีพัฒนาต่อ

- **คะแนนเท่ากันได้อันดับไม่เท่ากัน** เช่น 90 กับ 90 ได้อันดับ 1 กับ 2 → แก้ให้ถ้าคะแนนเท่ากับคนก่อนหน้าให้ใช้อันดับเดียวกัน
- **ช้าเมื่อข้อมูลเยอะมาก** (O(n²)) → ถ้าทั้งโรงเรียนหลายพันคน ควรใช้อัลกอริทึมที่เร็วกว่า เช่น Merge Sort หรือ `sort()` ของ Python
- **ยังทำงานต่อแม้เรียงเสร็จแล้ว** → ถ้ารอบไหนไม่มีการสลับเลยแปลว่าเรียงแล้ว ให้หยุดลูปได้เลย (ใช้ `break` เบรค = หยุดลูป)
- **ปิดโปรแกรมแล้วข้อมูลหาย** → บันทึกลงไฟล์ JSON
- **ยังไม่มีปุ่มลบทีละคน** → ใช้ `curselection()` เหมือน study_planner

# อธิบายโค้ด: โปรแกรมจัดผังที่นั่งสอบ (exam_seating.py)

## 1. โปรแกรมนี้ทำอะไร

- พิมพ์ **รายชื่อนักเรียน** บรรทัดละ 1 คน (มีชื่อตัวอย่าง 16 คนใส่ไว้ให้แล้ว)
- เลือก **จำนวนแถว** และ **จำนวนคอลัมน์** ของห้องสอบ
- กด **"สุ่มจัดที่นั่ง"** → โปรแกรมสลับรายชื่อแบบสุ่ม แล้ววาด **ผังห้องสอบ** ออกมาเป็นตาราง
- ติ๊ก **"นั่งเว้นแบบหมากรุก"** → นั่งเว้นโต๊ะสลับกันเหมือนตารางหมากรุก เพื่อกันลอกข้อสอบ
- **ค้นหาชื่อ** → โต๊ะของคนนั้นจะเป็นสีเหลือง และบอกว่านั่งแถวไหน คอลัมน์ไหน
- ถ้าโต๊ะไม่พอสำหรับนักเรียน จะขึ้นเตือน

**ทำไมทำ (เล่าให้อาจารย์ฟังได้):** ก่อนสอบกลางภาค ครูต้องนั่งเขียนผังที่นั่งด้วยมือทุกห้อง และนักเรียนต้องเบียดกันดูกระดาษหน้าห้องว่าตัวเองนั่งตรงไหน ผมเลยทำโปรแกรมที่สุ่มและวาดผังได้ในคลิกเดียว และใช้โอกาสนี้ฝึกเรื่อง **2D List (ข้อมูลแบบตาราง)** ซึ่งเป็นพื้นฐานของรูปภาพ เกมกระดาน และ Excel

## 4. อธิบายโค้ดทีละส่วน

### หน้าตาข้อมูล: 2D List ⭐

ห้องสอบ 3 แถว × 4 คอลัมน์ ถ้าเก็บเป็นลิสต์ซ้อนลิสต์จะได้แบบนี้

```python
seats = [
    ["บีม",  "ดาว",  "ชาย",  "พลอย"],   # แถว 0
    ["กร",   "ทิว",  "ญาญ่า", "งามตา"],  # แถว 1
    ["จูน",  "ปาล์ม", "ต้นกล้า", "ฟ้า"],   # แถว 2
]
```
- ลิสต์ใหญ่ 1 อัน มีลิสต์เล็ก 3 อัน (= 3 แถว) แต่ละลิสต์เล็กมี 4 ชื่อ (= 4 คอลัมน์)
- อ่านค่าด้วย **`seats[แถว][คอลัมน์]`** เช่น `seats[1][2]` → `"ญาญ่า"`
  - `seats[1]` = เปิดแถวที่ 1 ได้ `["กร", "ทิว", "ญาญ่า", "งามตา"]`
  - `[2]` = หยิบตัวที่ 2 ในแถวนั้น → `"ญาญ่า"`
- ⚠️ เริ่มนับจาก **0** เสมอ แต่บนจอผมแสดงเป็น `r + 1` เพื่อให้คนอ่านเริ่มที่ 1
- **เปรียบเทียบ:** เหมือนตารางเรียน หรือผังที่นั่งในโรงหนัง ที่บอกตำแหน่งด้วย "แถว + เลขที่นั่ง"

### ส่วนที่ 1: สร้างผังที่นั่ง

#### `is_usable(r, c)` — โต๊ะนี้นั่งได้ไหม
```python
if checker.get() == 1:
    return (r + c) % 2 == 0
return True
```
- ถ้าไม่ได้ติ๊กหมากรุก → ทุกโต๊ะนั่งได้
- ถ้าติ๊ก → นั่งได้เฉพาะโต๊ะที่ **แถว + คอลัมน์ เป็นเลขคู่**
- `%` (โมดูโล) = **เศษจากการหาร** `% 2 == 0` แปลว่า "หาร 2 ลงตัว" = เลขคู่

ลองคิดด้วยมือ (✅ = นั่งได้, ⬜ = เว้น):
```
          c=0      c=1      c=2      c=3
r=0   0 ✅    1 ⬜    2 ✅    3 ⬜
r=1   1 ⬜    2 ✅    3 ⬜    4 ✅
r=2   2 ✅    3 ⬜    4 ✅    5 ⬜
```
ได้ลายหมากรุกพอดี! ทุกคนไม่มีเพื่อนนั่งติดกันทั้งซ้าย ขวา หน้า หลัง

#### `make_seats()` — ปุ่มสุ่มจัดที่นั่ง ⭐

**ขั้นที่ 1: อ่านชื่อจากกล่องข้อความ**
```python
for line in text_names.get("1.0", tk.END).split("\n"):
    if line.strip() != "":
        names.append(line.strip())
```
- `text_names.get("1.0", tk.END)` = อ่านข้อความทั้งหมดใน Text (`"1.0"` = บรรทัด 1 ตัวอักษรที่ 0 คือจุดเริ่ม, `tk.END` = จนจบ)
- `.split("\n")` = **ตัดเป็นชิ้นทุกครั้งที่เจอการขึ้นบรรทัดใหม่** (`\n` = new line นิว-ไลน์)
- ข้ามบรรทัดว่าง เผื่อผู้ใช้กด Enter เกิน

**ขั้นที่ 2: นับความจุแล้วเช็คว่าพอไหม**
```python
for r in range(rows):
    for c in range(cols):
        if is_usable(r, c):
            capacity = capacity + 1
```
**loop ซ้อน loop** = วิธีมาตรฐานในการเดินผ่านทุกช่องของตาราง: loop นอกเลือกแถว, loop ในเดินทีละคอลัมน์ในแถวนั้น
(เหมือนครูเดินแจกข้อสอบ: เริ่มแถวแรก เดินซ้ายไปขวา แล้วค่อยลงแถวถัดไป)

**ขั้นที่ 3: สุ่ม แล้วใส่ชื่อลงตาราง**
```python
random.shuffle(names)
seats = []
index = 0
for r in range(rows):
    row = []
    for c in range(cols):
        if is_usable(r, c) and index < len(names):
            row.append(names[index])
            index = index + 1
        elif is_usable(r, c):
            row.append("(ว่าง)")
        else:
            row.append("")
    seats.append(row)
```
- `random.shuffle(names)` สลับลำดับรายชื่อแบบสุ่ม (เหมือนสับไพ่) แล้วค่อยใส่ตามลำดับ
- `index` เป็น **ตัวชี้** ว่าใส่ไปถึงชื่อคนที่เท่าไรแล้ว ใส่ 1 คนก็ขยับ 1
- แต่ละโต๊ะมี 3 กรณี: นั่งได้และยังมีคน → ใส่ชื่อ / นั่งได้แต่คนหมดแล้ว → `"(ว่าง)"` / โต๊ะเว้นตามลายหมากรุก → `""`
- สร้างลิสต์แถวเล็ก (`row`) ให้เต็มก่อน แล้วค่อยเอาไปต่อในลิสต์ใหญ่ (`seats`)

**`global seats`** อยู่บรรทัดแรกของฟังก์ชัน: เพราะเราสั่ง `seats = []` (สร้างใหม่) ในฟังก์ชัน ถ้าไม่บอก `global` Python จะคิดว่าเป็นตัวแปรใหม่ที่ใช้ได้แค่ในฟังก์ชันนี้ แล้ว `find_student()` จะมองไม่เห็น

### ส่วนที่ 2: วาดผัง + ค้นหา

#### `draw_seats(find_r, find_c)` — วาดตาราง
```python
x = 10 + c * CELL_W
y = TOP + r * CELL_H
```
แปลง "แถว/คอลัมน์" เป็น "พิกัดบนจอ": คอลัมน์ยิ่งมาก ยิ่งไปทางขวา แถวยิ่งมาก ยิ่งลงล่าง
- ตัวอย่าง: แถว 2 คอลัมน์ 3 → x = 10 + 3×90 = **280**, y = 45 + 2×50 = **145**
- `find_r, find_c` = ตำแหน่งที่ต้องทาสีเหลือง ส่ง `-1, -1` มาเมื่อไม่ต้องการไฮไลต์ (เพราะไม่มีแถวที่ -1)

#### `find_student()` — ค้นหาในตาราง
```python
for r in range(len(seats)):
    for c in range(len(seats[r])):
        if seats[r][c] == name:
            ...
            return
```
- ค้นหาใน 2D ก็ต้องใช้ **loop ซ้อน loop** ไล่ทุกช่อง (= Linear Search แบบ 2 มิติ)
- `len(seats)` = จำนวนแถว, `len(seats[r])` = จำนวนคอลัมน์ในแถวนั้น
- เจอแล้ว `return` ออกทันที ถ้าวนจนจบโดยไม่เจอ ก็จะไปถึงบรรทัด "ไม่พบ" ข้างล่าง

### ส่วนที่ 3: สร้างหน้าต่าง
แบ่งซ้าย-ขวาด้วย `pack(side="left")`: ซ้ายเป็นช่องกรอกข้อมูลและปุ่ม ขวาเป็น Canvas วาดผัง
- `spin_rows.delete(0, tk.END)` แล้ว `insert(0, "5")` = ตั้งค่าเริ่มต้นของ Spinbox เป็น 5
- `"\n".join(sample_names)` = เอารายชื่อมาต่อกันโดยคั่นด้วยการขึ้นบรรทัดใหม่ (ตรงข้ามกับ split)

## 5. ลำดับการทำงานทั้งหมด

```
เปิดโปรแกรม → ใส่ชื่อตัวอย่าง → รอเหตุการณ์
   ├─ "สุ่มจัดที่นั่ง" → อ่านแถว/คอลัมน์ → อ่านชื่อ (split ทีละบรรทัด)
   │                 → นับโต๊ะที่นั่งได้ (loop ซ้อน + is_usable)
   │                 → ไม่พอ? เตือน
   │                 → shuffle ชื่อ → วนทุกแถว วนทุกคอลัมน์ ใส่ชื่อทีละคน
   │                 → วาดผัง
   └─ "ค้นหา" → วนทุกแถว วนทุกคอลัมน์ → เจอ? วาดใหม่ทาสีเหลือง + บอกตำแหน่ง
                                       → ไม่เจอ? แจ้ง "ไม่พบ"
```

## 6. คำถามที่อาจารย์อาจถาม + แนวตอบ

**ถาม: 2D List คืออะไร ต่างจาก list ธรรมดายังไง?**
ตอบ: list ธรรมดาเหมือนแถวเรียงหนึ่งเส้น ใช้ตัวเลขตัวเดียวชี้ตำแหน่ง ส่วน 2D List คือ list ที่ข้างในเป็น list อีกที เหมือนตาราง ต้องใช้ 2 ตัวเลขคือแถวกับคอลัมน์ เช่น `seats[1][2]` ครับ

**ถาม: ทำไมต้องใช้ loop ซ้อน loop?**
ตอบ: เพราะตารางมี 2 มิติครับ loop นอกเดินทีละแถว loop ในเดินทีละช่องในแถวนั้น ถ้ามี 5 แถว 4 คอลัมน์ บรรทัดข้างในจะทำงาน 5 × 4 = 20 ครั้ง คือครบทุกโต๊ะพอดี

**ถาม: ลายหมากรุกคิดยังไง?**
ตอบ: ใช้ `(แถว + คอลัมน์) % 2 == 0` ครับ ช่องที่อยู่ติดกันทั้งแนวนอนและแนวตั้ง ผลบวกจะต่างกัน 1 เสมอ จึงสลับคู่-คี่ ทำให้ไม่มีใครนั่งติดกัน

**ถาม: `random.shuffle` สุ่มได้ยุติธรรมไหม?**
ตอบ: ยุติธรรมครับ Python ใช้อัลกอริทึม Fisher–Yates ที่ทุกลำดับมีโอกาสเกิดเท่ากัน แต่จริง ๆ คอมพิวเตอร์ใช้ "สุ่มเทียม" (pseudo-random) ที่คำนวณจากสูตร ไม่ได้สุ่มแท้ ๆ

**ถาม: ค้นหาชื่อในตารางใช้เวลาเท่าไร?**
ตอบ: แย่สุดต้องดูทุกช่อง คือ แถว × คอลัมน์ ช่อง เป็น Linear Search ครับ ถ้าอยากเร็วกว่านี้ทำ dict ชื่อ → (แถว, คอลัมน์) ไว้อีกอัน จะหาได้ทันที

**ถาม: ทำไมต้องมี `global`?**
ตอบ: เพราะในฟังก์ชันผมสร้าง `seats` ใหม่ด้วย `=` ถ้าไม่ประกาศ global Python จะถือว่าเป็นตัวแปรเฉพาะในฟังก์ชัน ฟังก์ชันค้นหาก็จะมองไม่เห็นผังใหม่ครับ

- **ใช้ความรู้:** 2D List (ลิสต์ซ้อนลิสต์), loop ซ้อน loop, โมดูโล `%` สร้างลายหมากรุก, `random.shuffle`, `split` / `join`, Linear Search ใน 2 มิติ, แปลงแถว/คอลัมน์เป็นพิกัดบน Canvas
- **ยากตรงไหน:** _(เขียนจากประสบการณ์จริงตอนพิมพ์โค้ดเอง)_

## 1. โปรแกรมนี้ทำอะไร

**ปัญหา:** คนจำนวนมากใช้รหัสผ่านง่าย ๆ เช่น `123456` หรือวันเกิด แฮกเกอร์จึงเดาได้ภายในไม่กี่วินาที

**โปรแกรมช่วยได้อย่างนี้:**
1. พิมพ์รหัสผ่านแล้วโปรแกรมให้คะแนนทันที (0–6 คะแนน) พร้อมแถบสี แดง / ส้ม / เขียว
2. บอกว่าควรแก้อะไร เช่น "เพิ่มตัวพิมพ์ใหญ่"
3. ถ้ากดปุ่ม "สุ่มรหัสผ่านที่ปลอดภัย" โปรแกรมจะสร้างรหัสแข็งแรงให้
4. กดปุ่ม "คัดลอก" เพื่อนำไปวางที่อื่น

## 5. อธิบายโค้ดทีละส่วน

### 5.1 ส่วนนำเข้าเครื่องมือ

```python
import tkinter as tk
import string
import secrets
```

- `import tkinter as tk` หมายถึงนำเครื่องมือสร้างหน้าต่างชื่อ **tkinter** (ทีเค-อินเตอร์ มาจาก **T**ool **k**it **inter**face = ชุดเครื่องมือสร้างหน้าจอ) เข้ามา
  - `as tk` (แอส = ในชื่อว่า) คือการตั้ง **ชื่อเล่น** ให้สั้นลง จากนั้นพิมพ์ `tk.Label` แทน `tkinter.Label`
- `import string` นำเข้าชุดตัวอักษรสำเร็จรูป เช่น a–z, A–Z, 0–9 เพื่อไม่ต้องพิมพ์เองทีละตัว
- `import secrets` (ซีเคร็ตส์ = ความลับ) คือเครื่องมือ **สุ่มแบบปลอดภัย**

> 💡 **จุดที่กรรมการอาจถาม: ทำไมใช้ `secrets` ไม่ใช้ `random`?**
> `random` (แรนดอม = สุ่ม) เหมาะกับเกม แต่ผลสุ่มของมันสามารถ **คาดเดาได้** ถ้ารู้ค่าตั้งต้น
> ส่วน `secrets` ออกแบบมาสำหรับงานความปลอดภัยโดยเฉพาะ จึงเดาไม่ได้ เอกสารทางการของ Python ก็แนะนำให้ใช้ `secrets` กับรหัสผ่าน

### 5.2 ข้อมูลตั้งต้น

```python
COMMON_PASSWORDS = [
    "123456", "12345678", "123456789", "password", "qwerty",
    "111111", "abc123", "iloveyou", "admin", "000000",
]
```

- `COMMON_PASSWORDS` (คอมมอน พาสเวิร์ดส์ = รหัสผ่านที่พบบ่อย) เป็น **list** ของรหัสยอดฮิต
- ตั้งชื่อด้วย **ตัวพิมพ์ใหญ่ทั้งหมด** ตามธรรมเนียมของ Python ซึ่งหมายถึง "ค่าคงที่ ไม่ควรแก้ระหว่างโปรแกรมทำงาน" (constant คอนสแตนต์ = ค่าคงที่)
- แฮกเกอร์มักลองรหัสพวกนี้ก่อนเสมอ วิธีนี้เรียกว่า **dictionary attack** (ดิกชันนารี แอทแทค = โจมตีด้วยการไล่ลองคำจากรายการ)

```python
LOWER = string.ascii_lowercase    # "abcdefghijklmnopqrstuvwxyz"
UPPER = string.ascii_uppercase    # "ABCDEFGHIJKLMNOPQRSTUVWXYZ"
DIGITS = string.digits            # "0123456789"
SYMBOLS = "!@#$%^&*()-_=+?"
```

- `lower` (โลเวอร์ = ตัวเล็ก), `upper` (อัปเปอร์ = ตัวใหญ่), `digits` (ดิจิทส์ = ตัวเลข), `symbols` (ซิมโบลส์ = สัญลักษณ์)
- `ascii` (แอสกี) คือมาตรฐานรหัสตัวอักษรภาษาอังกฤษในคอมพิวเตอร์
- `#` คือ **comment** (คอมเมนต์ = หมายเหตุ) Python จะข้ามทุกอย่างหลัง `#` ไป เราเขียนไว้ให้คนอ่าน

### 5.3 ฟังก์ชัน `has_char` (มีตัวอักษรประเภทนี้ไหม?)

```python
def has_char(password, char_set):
    for ch in password:
        if ch in char_set:
            return True
    return False
```

ชื่อมาจาก **has** (แฮส = มี) + **char**acter (แคแรกเตอร์ = ตัวอักษร)

ฟังก์ชันนี้รับข้อมูลเข้า 2 อย่าง (เรียกว่า **parameter** พารามิเตอร์ = ค่าที่ส่งเข้าฟังก์ชัน):
- `password` คือรหัสที่จะตรวจ
- `char_set` คือชุดตัวอักษรที่ต้องการหา (set เซ็ต = ชุด)

**ทีละบรรทัด:**
1. `for ch in password:` หมายถึง "หยิบตัวอักษรใน password มา **ทีละตัว** ตั้งชื่อว่า `ch`" (`for` = สำหรับแต่ละ..., `in` = ใน)
2. `if ch in char_set:` ถามว่า "ตัวนี้อยู่ในชุดที่เราหาไหม?"
3. `return True` ถ้าเจอแม้แต่ตัวเดียว ให้ตอบ **True** (ทรู = จริง) แล้วออกจากฟังก์ชันทันที
4. `return False` ถ้าวนครบทุกตัวแล้วยังไม่เจอ ให้ตอบ **False** (ฟอลส์ = เท็จ)

**เปรียบเทียบ:** เหมือนครูเดินตรวจกระเป๋านักเรียนทีละคนว่ามีโทรศัพท์ไหม พอเจอคนแรกก็หยุดและตอบว่า "มี" ถ้าตรวจครบทุกคนแล้วไม่เจอ ก็ตอบว่า "ไม่มี"

**ตัวอย่าง:** `has_char("abc1", DIGITS)` จะตรวจ a ไม่ใช่ตัวเลข, b ไม่ใช่, c ไม่ใช่, 1 ใช่! จึงได้ `True`

### 5.4 ฟังก์ชัน `check_password` (หัวใจของโปรแกรม ⭐)

```python
def check_password(password):
    score = 0
    tips = []
```
- เริ่มที่ **คะแนน 0** และ **รายการคำแนะนำว่างเปล่า** `[]`

```python
    if password.lower() in COMMON_PASSWORDS:
        return 0, ["รหัสนี้เป็นรหัสยอดฮิต ถูกเดาได้ภายในไม่กี่วินาที!"]
```
- `.lower()` แปลงเป็นตัวเล็กทั้งหมดก่อนเทียบ ดังนั้น `PASSWORD` กับ `Password` ก็ถูกจับได้เหมือนกัน
- ถ้าเป็นรหัสยอดฮิต ให้ **ได้ 0 ทันที** แล้วออกจากฟังก์ชัน ไม่ต้องตรวจข้ออื่นต่อ

```python
    if len(password) >= 8:
        score = score + 1
    else:
        tips.append("ควรยาวอย่างน้อย 8 ตัวอักษร")
```
- `len` มาจาก **len**gth (เลงธ์ = ความยาว) ใช้นับจำนวนตัวอักษร
- `>=` หมายถึง มากกว่าหรือเท่ากับ
- `score = score + 1` แปลว่า "เอาคะแนนเดิมบวก 1 แล้วเก็บกลับลงกล่องเดิม"
- `else` (เอลส์ = ไม่อย่างนั้น) ถ้าไม่ผ่าน ให้ทำส่วนนี้แทน
- `tips.append(...)` (อะเพนด์ = ต่อท้าย) คือเพิ่มคำแนะนำไปท้าย list

**เกณฑ์ทั้งหมด 6 ข้อ (ข้อละ 1 คะแนน):**

| ข้อ | เกณฑ์ | ทำไมสำคัญ |
|---|---|---|
| 1 | ยาว ≥ 8 ตัว | สั้นเกินไปจะไล่เดาครบได้เร็ว |
| 2 | ยาว ≥ 12 ตัว | ยิ่งยาว จำนวนแบบที่ต้องลองยิ่งเพิ่มมหาศาล |
| 3 | มีตัวพิมพ์เล็ก | เพิ่มชนิดตัวอักษร |
| 4 | มีตัวพิมพ์ใหญ่ | เพิ่มชนิดตัวอักษร |
| 5 | มีตัวเลข | เพิ่มชนิดตัวอักษร |
| 6 | มีสัญลักษณ์ | เพิ่มชนิดตัวอักษร |

> 💡 **ทำไมยาวกว่าและหลากหลายกว่าจึงปลอดภัยกว่า? (ใช้คณิตศาสตร์ ม.ปลาย)**
> ถ้าใช้แค่ตัวเลข 0–9 ความยาว 4 ตัว จะมีแบบที่เป็นไปได้ 10⁴ = 10,000 แบบ ซึ่งคอมพิวเตอร์ลองครบได้ในพริบตา
> ถ้าใช้ตัวอักษรทั้งหมด 77 ชนิด (ตัวเล็ก 26 + ตัวใหญ่ 26 + ตัวเลข 10 + สัญลักษณ์ 15) ความยาว 12 ตัว จะได้ 77¹² ≈ **4.3 × 10²²** แบบ ซึ่งต้องใช้เวลานานมาก
> นี่คือหลัก **การนับเบื้องต้น** (กฎการคูณ) ที่เรียนใน ม.ปลาย ถ้าพูดเรื่องนี้ตอนสัมภาษณ์ จะเห็นว่าคุณเชื่อมคณิตกับคอมพิวเตอร์ได้

```python
    return score, tips
```
- ส่งคืน **2 อย่างพร้อมกัน**: คะแนนและรายการคำแนะนำ

### 5.5 ฟังก์ชัน `get_level` (แปลงคะแนนเป็นระดับ)

```python
def get_level(score):
    if score <= 2:
        return "อ่อน", "red"
    elif score <= 4:
        return "ปานกลาง", "orange"
    else:
        return "แข็งแรง", "green"
```
- `elif` ย่อมาจาก **el**se **if** (เอลส์ อิฟ = ไม่อย่างนั้น ถ้า...)
- Python ตรวจจากบนลงล่าง พอเจอเงื่อนไขแรกที่จริงก็หยุดทันที
  - คะแนน 0–2 ได้ อ่อน (สีแดง)
  - คะแนน 3–4 ได้ ปานกลาง (สีส้ม)
  - คะแนน 5–6 ได้ แข็งแรง (สีเขียว)

### 5.6 ฟังก์ชัน `generate_password` (สุ่มรหัสผ่าน)

```python
def generate_password(length=16):
    all_chars = LOWER + UPPER + DIGITS + SYMBOLS
    while True:
        password = ""
        for i in range(length):
            password = password + secrets.choice(all_chars)
        score, tips = check_password(password)
        if score == 6:
            return password
```
- `generate` (เจเนอเรต = สร้าง)
- `length=16` คือ **ค่าเริ่มต้น** ถ้าเรียกโดยไม่บอกความยาว จะได้ 16 ตัว
- `LOWER + UPPER + ...` ใช้ `+` กับข้อความเพื่อ **ต่อข้อความเข้าด้วยกัน** จนเป็นชุดใหญ่ชุดเดียว
- `while True:` (ไวล์ = ในขณะที่) หมายถึง "วนไปเรื่อย ๆ ไม่มีที่สิ้นสุด" จนกว่าจะเจอ `return`
- `range(length)` (เรนจ์ = ช่วง) สร้างตัวเลข 0, 1, 2, ... ถึง 15 ทำให้ loop วน 16 รอบ
- `secrets.choice(all_chars)` (ช้อยส์ = เลือก) คือสุ่มหยิบมา 1 ตัว
- ต่อกัน 16 ตัว แล้ว **เอาไปตรวจด้วยฟังก์ชันของเราเอง** ถ้าได้ 6 คะแนนจึงส่งคืน ถ้าไม่ได้ก็วนสุ่มใหม่

> 💡 ตรงนี้คือการ **นำฟังก์ชันที่เขียนไว้แล้วกลับมาใช้ซ้ำ** (reuse รียูส) ซึ่งเป็นแนวคิดสำคัญของการเขียนโปรแกรม

### 5.7 ฟังก์ชันตอบสนองผู้ใช้: `update_result`

```python
def update_result(event=None):
    password = password_entry.get()
```
- `event=None` ต้องมีเพราะเวลา tkinter เรียกฟังก์ชันนี้ตอนพิมพ์ มันจะ **ส่งข้อมูลเหตุการณ์มาด้วย 1 ค่า** ส่วน `None` (นัน = ไม่มีค่า) ทำให้เราเรียกเองแบบไม่ส่งอะไรก็ได้
- `.get()` (เก็ท = เอามา) คือดึงข้อความที่ผู้ใช้พิมพ์ในช่อง

```python
    if password == "":
        level_label.config(text="ระดับ: -", fg="black")
        tips_label.config(text="")
        bar_canvas.coords(bar, 0, 0, 0, 20)
        return
```
- `==` (เท่ากับสองตัว) ใช้ **เปรียบเทียบ** ว่าเท่ากันไหม ส่วน `=` ตัวเดียวใช้ **เก็บค่า** ห้ามสับสน
- `.config(...)` (คอนฟิก มาจาก configure = ตั้งค่า) ใช้เปลี่ยนข้อความหรือสีของ widget
- `fg` ย่อมาจาก **f**ore**g**round (โฟร์กราวด์ = สีตัวอักษร)
- `return` เปล่า ๆ แปลว่า "จบฟังก์ชันตรงนี้เลย"

```python
    score, tips = check_password(password)
    level, color = get_level(score)
```
- ฟังก์ชันคืนค่า 2 อย่าง เราจึง **แกะใส่ตัวแปร 2 ตัวพร้อมกัน** ได้

```python
    level_label.config(text=f"ระดับ: {level}  ({score}/6 คะแนน)", fg=color)
```
- `f"..."` เรียกว่า **f-string** (เอฟ-สตริง, f มาจาก **f**ormat = จัดรูปแบบ) ใช้ใส่ค่าตัวแปรใน `{ }` ลงไปในข้อความ
  - เช่น ถ้า level="อ่อน" และ score=2 จะได้ `ระดับ: อ่อน  (2/6 คะแนน)`

```python
    bar_width = score / 6 * 300
    bar_canvas.coords(bar, 0, 0, bar_width, 20)
    bar_canvas.itemconfig(bar, fill=color)
```
- คำนวณความกว้างแถบ: ถ้าคะแนนเต็ม 6 แถบจะกว้าง 300 พิกเซล ถ้าได้ 3 จะได้ 3/6 × 300 = 150 (ครึ่งแถบ) ซึ่งก็คือ **บัญญัติไตรยางศ์** ธรรมดา
- `coords` ย่อมาจาก **coord**inate**s** (โคออร์ดิเนตส์ = พิกัด) ใช้กำหนดพิกัดสี่เหลี่ยมใหม่ (x1, y1, x2, y2) คือมุมซ้ายบนไปมุมขวาล่าง
- `fill` (ฟิล = เติมสี)

```python
    if len(tips) == 0:
        tips_label.config(text="✔ ยอดเยี่ยม! รหัสผ่านนี้ปลอดภัย")
    else:
        text = ""
        for tip in tips:
            text = text + "• " + tip + "\n"
        tips_label.config(text=text)
```
- ถ้าไม่มีคำแนะนำเลย แปลว่าผ่านทุกข้อ
- ถ้ามี ให้ต่อคำแนะนำทีละข้อ โดย `\n` คือ **ขึ้นบรรทัดใหม่** (n มาจาก **n**ew line นิวไลน์)

### 5.8 ฟังก์ชันอื่น ๆ

**`toggle_show`** (ท็อกเกิล = สลับเปิด/ปิด)
```python
def toggle_show():
    if show_var.get() == 1:
        password_entry.config(show="")
    else:
        password_entry.config(show="*")
```
- ช่องติ๊กจะเก็บค่า 1 (ติ๊ก) หรือ 0 (ไม่ติ๊ก)
- `show="*"` ให้แสดง `*` แทนตัวจริง ส่วน `show=""` ให้แสดงตัวจริง

**`on_generate`** (on = เมื่อ, ทำงานเมื่อกดปุ่มสุ่ม)
```python
    new_password = generate_password()
    password_entry.delete(0, tk.END)
    password_entry.insert(0, new_password)
    update_result()
```
- ลบข้อความเดิมในช่องตั้งแต่ตำแหน่ง 0 ถึง `END` (เอนด์ = ท้ายสุด)
- `insert` (อินเสิร์ต = แทรก) ใส่รหัสใหม่ที่ตำแหน่ง 0
- เรียก `update_result()` เพื่อให้แถบสีอัปเดตทันที

**`on_copy`** (คอปปี้ = คัดลอก)
```python
    root.clipboard_clear()
    root.clipboard_append(password_entry.get())
    copy_button.config(text="คัดลอกแล้ว ✔")
    root.after(1500, lambda: copy_button.config(text="คัดลอก"))
```
- `clipboard` (คลิปบอร์ด) คือที่พักข้อมูลชั่วคราวเวลาเรากด Copy / Paste
- `root.after(1500, ...)` (อาฟเตอร์ = หลังจาก) หมายถึง "อีก 1500 มิลลิวินาที (1.5 วินาที) ค่อยทำสิ่งนี้" คือเปลี่ยนข้อความปุ่มกลับเป็นเดิม
- `lambda` (แลมบ์ดา) คือ **ฟังก์ชันสั้น ๆ ไม่มีชื่อ** เขียนบรรทัดเดียว ใช้เมื่อขี้เกียจ `def` ฟังก์ชันใหม่สำหรับงานเล็ก ๆ

### 5.9 ส่วนสร้างหน้าต่าง (GUI)

```python
root = tk.Tk()
root.title("ตรวจความแข็งแรงของรหัสผ่าน")
root.geometry("420x460")
root.resizable(False, False)
```
- `tk.Tk()` สร้าง **หน้าต่างหลัก** ตั้งชื่อว่า `root` (รูท = ราก เพราะทุก widget งอกออกมาจากตรงนี้)
- `title` (ไทเทิล = ชื่อเรื่อง) คือข้อความบนแถบหัวหน้าต่าง
- `geometry` (จีออเมทรี = เรขาคณิต) คือขนาด กว้าง x สูง
- `resizable(False, False)` ห้ามยืดหน้าต่างทั้งแนวนอนและแนวตั้ง

**รูปแบบการสร้าง widget ทุกตัว (จำแค่นี้พอ):**
```python
ชื่อ = tk.ชนิดWidget(อยู่ในอะไร, ตั้งค่าต่าง ๆ)
ชื่อ.pack()      # วางลงบนหน้าจอ
```

| Widget | อ่านว่า | คืออะไร |
|---|---|---|
| `Label` | เลเบิล | ป้ายข้อความ |
| `Entry` | เอนทรี | ช่องให้พิมพ์ |
| `Button` | บัตทั่น | ปุ่ม |
| `Checkbutton` | เช็คบัตทั่น | ช่องติ๊ก |
| `Canvas` | แคนวาส | ผืนผ้าใบ ใช้วาดรูป |
| `Frame` | เฟรม | กรอบ ใช้จัดกลุ่ม widget |

- `.pack()` (แพ็ค = จัดวาง) วางเรียงจากบนลงล่าง ส่วน `pady=15` (แพด-วาย) คือเว้นระยะบน-ล่าง 15 พิกเซล
- `pack(side="left")` วางเรียงจากซ้ายไปขวาแทน (ใช้กับปุ่มที่อยู่ในแถวเดียวกัน)

```python
password_entry.bind("<KeyRelease>", update_result)
```
- `bind` (ไบนด์ = ผูก) คือ **ผูกเหตุการณ์กับฟังก์ชัน**
- `<KeyRelease>` (คีย์ รีลีส = ปล่อยนิ้วจากแป้น) ทำให้ทุกครั้งที่พิมพ์ 1 ตัว ฟังก์ชัน `update_result` จะทำงาน ผลจึงอัปเดตทันที

```python
tk.Button(button_frame, text="สุ่มรหัสผ่านที่ปลอดภัย", command=on_generate)
```
- `command=on_generate` (คอมมานด์ = คำสั่ง) บอกว่าเมื่อกดปุ่ม ให้เรียกฟังก์ชันนี้
- ⚠️ เขียน `on_generate` **ไม่มีวงเล็บ** เพราะเราส่ง "ตัวฟังก์ชัน" ไปให้ปุ่มเก็บไว้เรียกทีหลัง ถ้าใส่วงเล็บ `on_generate()` มันจะทำงานทันทีตอนเปิดโปรแกรม

```python
bar = bar_canvas.create_rectangle(0, 0, 0, 20, fill="red", width=0)
```
- `create_rectangle` (ครีเอต เร็กแทงเกิล = สร้างสี่เหลี่ยม) เริ่มด้วยความกว้าง 0 (มองไม่เห็น) แล้วค่อยยืดตามคะแนน

```python
root.mainloop()
```
- `mainloop` (เมนลูป = วงวนหลัก) ทำให้โปรแกรม **รอฟังเหตุการณ์ตลอดเวลา** (รอว่าผู้ใช้จะกดหรือพิมพ์อะไร) จนกว่าจะปิดหน้าต่าง
- ถ้าไม่มีบรรทัดนี้ หน้าต่างจะเปิดแล้วปิดทันที

## 7. คำถามที่กรรมการอาจถาม และแนวตอบ

> ⚠️ แนวตอบด้านล่างเป็นแค่ **ไอเดีย** ให้ตอบด้วยคำพูดของตัวเองตามที่เข้าใจจริงเท่านั้น

**Q: ทำโปรเจกต์นี้ทำไม?**
แนวตอบ: สนใจเรื่องความปลอดภัยไซเบอร์ เห็นข่าวหน่วยงานโดนแฮก และเห็นว่าคนรอบตัวใช้รหัสง่าย ๆ จึงอยากทำเครื่องมือที่ช่วยให้คนตั้งรหัสที่ปลอดภัยขึ้น

**Q: โปรแกรมให้คะแนนยังไง?**
แนวตอบ: มี 6 เกณฑ์ ข้อละ 1 คะแนน (อธิบายตามตารางในข้อ 5.4) ถ้าเป็นรหัสยอดฮิตจะได้ 0 ทันที

**Q: ทำไมรหัสยาวถึงปลอดภัยกว่า?**
แนวตอบ: ใช้หลักการนับ จำนวนแบบ = (ชนิดตัวอักษร)^(ความยาว) ความยาวจึงเพิ่มจำนวนแบบแบบยกกำลัง

**Q: ทำไมใช้ `secrets` ไม่ใช้ `random`?**
แนวตอบ: ดูข้อ 5.1

**Q: ส่วนไหนยากที่สุด?** (ตอบตามความจริงของตัวเอง เช่น)
อาจเป็นการทำให้ผลอัปเดตทันทีตอนพิมพ์ ซึ่งต้องเรียนเรื่อง `bind` กับ event

**Q: ถ้าพัฒนาต่อจะทำอะไร?**
- ใช้รายการรหัสยอดฮิตที่ใหญ่ขึ้น (ของจริงมีเป็นล้านรายการ)
- ตรวจรหัสที่มีชื่อหรือวันเกิดของผู้ใช้ปนอยู่
- ประมาณเวลาที่แฮกเกอร์ใช้เดา เช่น "ใช้เวลาเดา 3 ปี"
- ตรวจแบบเรียงแป้น เช่น `qwerty` หรือ `asdf`

**Q: ข้อจำกัดของโปรแกรมนี้?** (การพูดถึงข้อจำกัดเองจะดูดีมาก)
- `Password1!` ได้คะแนนเต็ม 6 แต่จริง ๆ เป็นรูปแบบที่คนใช้บ่อยมาก เกณฑ์แบบนับข้อจึงยังไม่ฉลาดพอ

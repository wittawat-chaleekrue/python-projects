## 1. โปรแกรมนี้ทำอะไร

**ปัญหา:** หนังสือ ลูกบอล หรืออุปกรณ์ในห้องเรียนหรือชมรมหายบ่อย เพราะ
- ไม่รู้ว่าใครยืมไป
- ไม่รู้ว่ายืมไปตั้งแต่เมื่อไหร่ และควรคืนเมื่อไหร่
- ไม่มีใครตามทวง

**โปรแกรมช่วยได้อย่างนี้:**
1. เพิ่มหรือลบรายการของในระบบ
2. บันทึก **ยืม** (ใคร / วันที่ยืม / กำหนดคืนซึ่งคำนวณให้อัตโนมัติ)
3. บันทึก **คืน**
4. แสดงสถานะด้วยสี: 🟩 ว่าง / 🟨 ถูกยืม / 🟥 **เลยกำหนด**
5. ค้นหาจากชื่อของหรือชื่อผู้ยืม (ผลขึ้นทันทีที่พิมพ์)
6. สรุปจำนวนของแต่ละสถานะ

## 5. อธิบายโค้ดทีละส่วน

### 5.1 นำเข้าเครื่องมือ

```python
from datetime import date, timedelta
```
- ของใหม่คือ `timedelta` ใช้ **บวกหรือลบวัน** กับวันที่
  - เช่น `date(2026, 10, 17) + timedelta(days=7)` ได้ `2026-10-24`
  - มันรู้เองว่าเดือนไหนมี 30 หรือ 31 วัน และข้ามเดือนหรือข้ามปีให้ถูกต้อง เราไม่ต้องคิดเอง

### 5.2 ส่วนที่ 1: ออกแบบตาราง

```sql
CREATE TABLE IF NOT EXISTS items (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    name        TEXT,
    borrower    TEXT DEFAULT '',
    borrow_date TEXT DEFAULT '',
    due_date    TEXT DEFAULT ''
)
```

| คอลัมน์ | ความหมาย | ตัวอย่าง |
|---|---|---|
| `id` | รหัสของ (ห้ามซ้ำ) | 1 |
| `name` | ชื่อของ | หนังสือคณิต ม.6 |
| `borrower` | ผู้ยืม (ว่าง = ไม่มีคนยืม) | สมชาย |
| `borrow_date` | วันที่ยืม | 2026-10-17 |
| `due_date` | กำหนดคืน | 2026-10-24 |

- `DEFAULT ''` (ดีฟอลต์) หมายถึง **ถ้าไม่ได้ใส่ค่า ให้เป็นข้อความว่างโดยอัตโนมัติ** ตอนเพิ่มของใหม่จึงใส่แค่ชื่อพอ

> 💡 **การตัดสินใจออกแบบ (design decision):** ผมเลือกใช้ **ตารางเดียว** เพื่อให้เรียบง่าย ข้อเสียคือ **ไม่มีประวัติ** เพราะพอคืนของแล้ว ข้อมูลผู้ยืมจะถูกล้าง จึงไม่รู้ว่าเมื่อเดือนที่แล้วใครเคยยืม
> ถ้าพัฒนาต่อ ควรแยกเป็น 2 ตาราง คือ `items` (ของ) กับ `loans` (ประวัติการยืมทุกครั้ง)
> **การรู้ข้อจำกัดของงานตัวเองและอธิบายได้ จะทำให้กรรมการประทับใจมาก**

**สถานะไม่ได้เก็บในฐานข้อมูล แต่ "คำนวณ" ทุกครั้งที่แสดง** เพราะสถานะ "เลยกำหนด" เปลี่ยนไปเองตามวันเวลา ถ้าเก็บไว้ เมื่อวันผ่านไปค่าที่เก็บจะผิด

### 5.3 ส่วนที่ 2: `get_status` (หัวใจของโปรแกรม ⭐)

```python
def get_status(borrower, due_date):
    if borrower == "":
        return "ว่าง"
    today = str(date.today())
    if today > due_date:
        return "เลยกำหนด"
    return "ถูกยืม"
```
**อ่านเป็นภาษาคน:**
1. ถ้าไม่มีชื่อผู้ยืม แปลว่า **ว่าง**
2. ถ้ามีคนยืม และวันนี้ **เลย** วันกำหนดคืนแล้ว แปลว่า **เลยกำหนด**
3. ถ้าไม่เข้าทั้งสองกรณี แปลว่า **ถูกยืม** (ยังไม่ถึงกำหนด)

> 💡 **ทำไมเอาวันที่แบบข้อความมาเทียบ `>` ได้?**
> Python เทียบข้อความ **ทีละตัวจากซ้ายไปขวา** เหมือนการเรียงคำในพจนานุกรม
> วันที่ของเราเขียนแบบ **ปี-เดือน-วัน** (`2026-10-17`) หลักที่ใหญ่สุด (ปี) จึงอยู่ซ้ายสุด การเทียบข้อความจึงให้ผลเหมือนการเทียบวันที่จริง
> - `"2026-10-25" > "2026-10-24"` เป็นจริง ✅
> - `"2027-01-01" > "2026-12-31"` เป็นจริง ✅
> รูปแบบนี้เป็นมาตรฐานสากลชื่อ **ISO 8601** (ไอเอสโอ) ที่ออกแบบให้เรียงลำดับง่ายแบบนี้โดยเฉพาะ
> ⚠️ ถ้าเขียนแบบไทย `17/10/2026` จะเทียบแบบนี้ไม่ได้ เพราะวันอยู่ซ้ายสุด

### 5.4 `get_selected`

```python
def get_selected():
    selected = table.selection()
    if len(selected) == 0:
        messagebox.showinfo("แจ้งเตือน", "กรุณาคลิกเลือกของในตารางก่อน")
        return None
    return table.item(selected[0], "values")
```
- คล้ายกับในโปรเจกต์ร้านค้า แต่คืนค่า **ทั้งแถว** เช่น `("1", "หนังสือคณิต", "ถูกยืม", "สมชาย", "2026-10-17", "2026-10-24")`
- ฟังก์ชันอื่นจึงหยิบได้ทั้ง id, ชื่อ และสถานะ ด้วย `row[0]`, `row[1]`, `row[2]`

### 5.5 ส่วนที่ 3: ฟังก์ชันหลัก

#### `load_data` (แสดงข้อมูล + ค้นหา + นับสรุป)

```python
    keyword = search_entry.get().strip()
    cur.execute("SELECT * FROM items WHERE name LIKE ? OR borrower LIKE ? ORDER BY id",
                ("%" + keyword + "%", "%" + keyword + "%"))
```
- `LIKE "%คำ%"` แปลว่า **มีคำนี้อยู่ตรงไหนก็ได้** (`%` ข้างหน้าและข้างหลังแปลว่า มีอะไรนำหน้าหรือตามหลังก็ได้)
  - ค้นว่า "คณิต" จะเจอ "หนังสือ**คณิต** ม.6"
- `OR` (ออร์ = หรือ) ทำให้เจอถ้าคำนั้นอยู่ใน **ชื่อของ หรือ ชื่อผู้ยืม** อย่างใดอย่างหนึ่ง
- ถ้าช่องค้นหาว่าง จะได้ `"%%"` ซึ่งตรงกับทุกอย่าง จึงแสดงทั้งหมด (ไม่ต้องเขียน if แยกเหมือนโปรเจกต์ร้านค้า)
- ใช้ `?` ป้องกัน SQL Injection เหมือนเดิม

```python
    count_free = 0
    count_borrowed = 0
    count_late = 0

    for r in rows:
        item_id, name, borrower, borrow_date, due_date = r
        status = get_status(borrower, due_date)
        table.insert("", tk.END,
                     values=(item_id, name, status, borrower, borrow_date, due_date),
                     tags=(status,))
        if status == "ว่าง":
            count_free = count_free + 1
        elif status == "ถูกยืม":
            count_borrowed = count_borrowed + 1
        else:
            count_late = count_late + 1
```
- วนทีละแถว → **คำนวณสถานะ** → ใส่ลงตาราง (ติดป้ายสีตามสถานะ) → **นับ** แต่ละสถานะ
- การนับ (`count = count + 1`) เหมือนการ **ขีดนับคะแนนบนกระดาน** ทีละขีด

#### `add_item` (เพิ่มของ)

```python
    cur.execute("INSERT INTO items (name) VALUES (?)", (name,))
```
- ใส่แค่ชื่อ ส่วนคอลัมน์อื่นเป็นค่าว่างตาม `DEFAULT` สถานะจึงเป็น "ว่าง" ทันที

#### `delete_item` (ลบของ พร้อมกฎป้องกัน)

```python
    item_id, name, status = row[0], row[1], row[2]
    if status != "ว่าง":
        messagebox.showwarning("ลบไม่ได้", f"'{name}' ยังถูกยืมอยู่ ต้องคืนก่อนจึงจะลบได้")
        return
```
- `!=` แปลว่า **ไม่เท่ากับ**
- **กฎทางธุรกิจ (business rule บิสซิเนส รูล):** ห้ามลบของที่ยังมีคนยืมอยู่ ไม่อย่างนั้นจะไม่มีหลักฐานว่าใครยืมไป

#### `borrow_item` (ยืม ⭐)

```python
    if status != "ว่าง":
        messagebox.showwarning("ยืมไม่ได้", f"'{name}' ถูกยืมไปแล้ว")
        return
```
- กฎ: **ของ 1 ชิ้น ยืมได้ทีละคน**

```python
    try:
        days = int(days_entry.get())
    except ValueError:
        ...
    if days < 1:
        ...
```
- `int` (อินท์ มาจาก **int**eger = จำนวนเต็ม) แปลงข้อความเป็นจำนวนเต็ม ถ้ากรอก "abc" หรือ "2.5" จะแปลงไม่ได้ จึงเข้า except
- ต้องยืมอย่างน้อย 1 วัน

```python
    today = date.today()
    due = today + timedelta(days=days)
```
- **กำหนดคืน = วันนี้ + จำนวนวันที่ให้ยืม** เช่น 17 ต.ค. + 7 วัน = 24 ต.ค.

```python
    cur.execute("UPDATE items SET borrower=?, borrow_date=?, due_date=? WHERE id=?",
                (borrower, str(today), str(due), item_id))
```
- **การยืมไม่ใช่การเพิ่มแถวใหม่ แต่เป็นการ UPDATE แถวเดิม** โดยเติมชื่อผู้ยืมและวันที่ลงไป
- `str(today)` แปลงวันที่เป็นข้อความรูปแบบ `"2026-10-17"` ก่อนเก็บ

#### `return_item` (คืน)

```python
    cur.execute("UPDATE items SET borrower='', borrow_date='', due_date='' WHERE id=?",
                (item_id,))
```
- การคืนคือ **ล้างข้อมูลผู้ยืมให้ว่าง** ซึ่งทำให้ `get_status` ตอบว่า "ว่าง" อัตโนมัติ
- สังเกตว่า **ยืมกับคืนใช้ UPDATE ทั้งคู่** ต่างกันแค่ค่าที่ใส่

### 5.6 ส่วนที่ 4: GUI (เฉพาะส่วนที่ใหม่)

**`LabelFrame`** (เลเบิล เฟรม) คือกรอบที่มีหัวข้อ ใช้แบ่งหน้าจอเป็นโซน "เพิ่มของ" กับ "ยืม/คืน" ให้ผู้ใช้เข้าใจง่าย

**ค้นหาทันทีที่พิมพ์:**
```python
search_entry.bind("<KeyRelease>", lambda event: load_data())
```
- ทุกครั้งที่ปล่อยแป้น ให้เรียก `load_data()` ใหม่
- ใช้ `lambda event: ...` เพราะ `bind` จะส่ง event มา 1 ค่า แต่ `load_data()` ไม่รับค่าใด ๆ เราจึงสร้างฟังก์ชันสั้น ๆ มารับ event แล้วเรียก `load_data()` ต่อ

**สร้างหัวตารางด้วย loop แทนการเขียนซ้ำ 6 ครั้ง:**
```python
columns = ("id", "name", "status", "borrower", "borrow_date", "due_date")
headings = ["รหัส", "ชื่อของ", "สถานะ", "ผู้ยืม", "วันที่ยืม", "กำหนดคืน"]
widths = [50, 220, 90, 140, 100, 100]
for i in range(len(columns)):
    table.heading(columns[i], text=headings[i])
    table.column(columns[i], width=widths[i], anchor="center")
```
- มี 3 รายการที่ **ลำดับตรงกัน** ช่องที่ i ของทุกรายการเป็นเรื่องเดียวกัน
- `range(len(columns))` ได้ 0, 1, 2, 3, 4, 5 จึงวนครบ 6 คอลัมน์
- **หลักการ DRY** (ดราย = **D**on't **R**epeat **Y**ourself = อย่าเขียนซ้ำ) ถ้าวันหน้าเพิ่มคอลัมน์ ก็แค่เพิ่มของลงใน list

**สีตามสถานะ:**
```python
table.tag_configure("ว่าง", background="#e3f6e3")       # เขียว
table.tag_configure("ถูกยืม", background="#fff5d6")     # เหลือง
table.tag_configure("เลยกำหนด", background="#fbd4d4")   # แดง
```
- ใช้หลัก **สีไฟจราจร** ที่ทุกคนเข้าใจทันทีโดยไม่ต้องอ่าน

```

        ↓
borrow_item()

   • สถานะ == "ว่าง" ✅
   • ชื่อผู้ยืมไม่ว่าง ✅
   • days = int("7") = 7 ✅
   • due = 2026-10-17 + 7 วัน = 2026-10-24
        ↓
UPDATE items SET borrower='สมชาย', borrow_date='2026-10-17', due_date='2026-10-24' WHERE id=1
        ↓
commit → load_data() → แถวเปลี่ยนเป็นสีเหลือง "ถูกยืม"
        ↓
... เวลาผ่านไปถึง 25 ต.ค. แล้วเปิดโปรแกรม ...
        ↓
get_status("สมชาย", "2026-10-24") → "2026-10-25" > "2026-10-24" → "เลยกำหนด" 🟥
```

## 7. คำถามที่กรรมการอาจถาม และแนวตอบ

> ⚠️ ตอบด้วยคำพูดของตัวเองตามที่เข้าใจจริงเท่านั้น

**Q: โปรแกรมรู้ได้ยังไงว่าของเลยกำหนด?**
แนวตอบ: ไม่ได้เก็บสถานะไว้ แต่คำนวณทุกครั้งที่แสดง โดยเทียบวันนี้กับวันกำหนดคืน (ข้อ 5.3)

**Q: ทำไมไม่เก็บสถานะในฐานข้อมูลเลย?**
แนวตอบ: สถานะเลยกำหนดเปลี่ยนตามเวลาเอง ถ้าเก็บไว้ต้องคอยอัปเดตทุกวัน ไม่อย่างนั้นข้อมูลจะผิด

**Q: คำนวณวันกำหนดคืนยังไง? ข้ามเดือนได้ไหม?**
แนวตอบ: ใช้ `timedelta` บวกวัน มันจัดการวันในแต่ละเดือนและข้ามปีให้ถูกต้องเอง

**Q: ถ้าสองคนยืมของชิ้นเดียวกันพร้อมกันได้ไหม?**
แนวตอบ: ไม่ได้ เพราะตรวจสถานะก่อนว่าต้อง "ว่าง" เท่านั้น

**Q: ข้อจำกัดของโปรแกรม?**
- ไม่เก็บประวัติการยืม (ตารางเดียว) จึงควรแยกตาราง `loans`
- ผู้ยืมพิมพ์ชื่อเอง อาจพิมพ์ต่างกัน เช่น "สมชาย" กับ "ด.ช.สมชาย" ควรมีตารางรายชื่อนักเรียน
- ไม่มีการแจ้งเตือนผู้ยืมโดยตรง

**Q: ถ้าพัฒนาต่อ?**
- เก็บประวัติการยืมทั้งหมด
- สแกน **QR code / บาร์โค้ด** แทนการคลิก
- แจ้งเตือนผ่าน LINE เมื่อใกล้ครบกำหนด
- ทำเป็นเว็บให้ทุกคนเข้าดูได้จากมือถือ

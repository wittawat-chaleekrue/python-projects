## ⚙️ เตรียมเครื่อง Mac (ทำครั้งเดียว)

**1. ตรวจว่ามี Python ที่ใช้ tkinter ได้ไหม** โดยเปิด Terminal แล้วพิมพ์:
```bash
python3 -m tkinter
```
- `-m` ย่อมาจาก **m**odule หมายถึง "รันมอดูลชื่อนี้"
- ถ้ามี **หน้าต่างเล็ก ๆ เด้งขึ้นมา** แสดงว่าใช้ได้แล้ว ✅ ปิดหน้าต่างแล้วไปขั้นตอนที่ 2 ได้เลย
- ถ้าขึ้น error ให้ติดตั้ง Python จาก **python.org** → Downloads → macOS (ตัวติดตั้งจากเว็บนี้มี tkinter มาให้ในตัว)
  - ถ้าติดตั้ง Python ผ่าน Homebrew ให้พิมพ์ `brew install python-tk` เพิ่ม

**2. รันโปรแกรม** เช่น:
```bash
cd ~/python/password_checker
python3 password_checker.py
```

> SQLite (ฐานข้อมูล) มีมากับ Python อยู่แล้ว ไม่ต้องติดตั้งเพิ่ม

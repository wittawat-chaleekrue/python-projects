# อธิบายโค้ด: โปรแกรมแผนผังเครือญาติ (family_tree.py)

## 1. โปรแกรมนี้ทำอะไร

- แสดง **แผนผังเครือญาติแบบต้นไม้** ตั้งแต่ ทวด → ปู่ → พ่อ / ลุง / อา → ฉัน / น้อง / ลูกพี่ลูกน้อง (กดลูกศรหน้าชื่อเพื่อพับหรือกางได้)
- **คลิกชื่อ** แล้วกด
  - **"นับลูกหลาน"** → บอกว่าคนนี้มีลูก หลาน เหลน รวมทั้งหมดกี่คน
  - **"ดูสายบรรพบุรุษ"** → ไล่ขึ้นไปถึงบนสุด เช่น `ฉัน → พ่อ → ปู่ → ทวด`
- **เพิ่มคนใหม่** เป็นลูกของคนที่เลือกได้ (ถ้าชื่อซ้ำจะเตือน)

**ทำไมทำ (เล่าให้อาจารย์ฟังได้):** ตอนงานบุญหรืองานรวมญาติ ผมมักจำไม่ได้ว่าใครเป็นญาติฝั่งไหน เรียกว่าอะไร ผมเลยทำแผนผังเครือญาติ และพบว่าครอบครัวคือโครงสร้างข้อมูลแบบ **Tree (ต้นไม้)** ซึ่งเหมาะกับการเขียนโปรแกรมแบบ **Recursion (ฟังก์ชันที่เรียกตัวเอง)** มาก เพราะ "ลูกของเรา ก็มีลูกของเขาเองต่อไปอีก"

> 💡 ชื่อในโค้ดเป็นคำเรียกทั่วไป แก้เป็นชื่อญาติจริงได้ใน `children`

## 4. อธิบายโค้ดทีละส่วน

### หน้าตาข้อมูล: Tree ⭐

```python
ROOT = "ทวด"
children = {
    "ทวด": ["ปู่", "ปู่รอง"],
    "ปู่": ["ลุง", "พ่อ", "อา"],
    "พ่อ": ["ฉัน", "น้องมิว"],
    "ฉัน": [],
    ...
}
```
- dict จับคู่ **ชื่อ → รายชื่อลูก** คนที่ยังไม่มีลูกก็ต้องมีชื่ออยู่ แต่เป็นลิสต์ว่าง `[]`
- `ROOT` เขียนตัวพิมพ์ใหญ่หมด = ธรรมเนียมของ Python ว่าเป็น **ค่าคงที่** ไม่ควรเปลี่ยน

วาดออกมาเป็นต้นไม้ (กลับหัว รากอยู่บน):
```
ทวด
├── ปู่
│   ├── ลุง ── พี่ต้น, พี่ฝน
│   ├── พ่อ ── ฉัน, น้องมิว
│   └── อา
└── ปู่รอง
    └── น้าแก้ว ── น้องเก่ง
```
- **Tree** = โครงสร้างที่แต่ละจุดมีพ่อแม่ได้ **1 คน** แต่มีลูกได้ **หลายคน** และมีรากบนสุดแค่ 1 จุด
- **เปรียบเทียบ:** เหมือนโฟลเดอร์ในเครื่อง Mac ที่โฟลเดอร์หนึ่งมีโฟลเดอร์ย่อยได้หลายอัน และโฟลเดอร์ย่อยก็มีโฟลเดอร์ย่อยต่อได้อีก
- ต่างจาก **Graph** (โปรเจค school_navigator) ตรงที่ Tree **ไม่มีทางวนกลับมาที่เดิม**

### ส่วนที่ 1: Recursion ⭐⭐

**Recursion คืออะไร?** = ฟังก์ชันที่ **แก้ปัญหาใหญ่ โดยเรียกตัวเองไปแก้ปัญหาเล็กกว่า** จนเล็กสุดที่ตอบได้ทันที
- **เปรียบเทียบ:** ตุ๊กตาแม่ลูกดก (Matryoshka) ของรัสเซีย เปิดตัวใหญ่เจอตัวเล็กกว่าข้างใน เปิดต่อไปเรื่อย ๆ จนเจอตัวเล็กสุดที่เปิดไม่ได้แล้ว = **จุดหยุด**
- ทุก recursion ต้องมี 2 อย่าง:
  1. **Base case (จุดหยุด)** — กรณีที่ตอบได้เลยไม่ต้องเรียกตัวเอง
  2. **Recursive case (เรียกตัวเอง)** — กับปัญหาที่ **เล็กลง** เข้าใกล้จุดหยุดทุกครั้ง
- ถ้าไม่มีจุดหยุด จะเรียกตัวเองไม่จบ จน Python แจ้ง `RecursionError` (เกินประมาณ 1,000 ชั้น)

#### ฟังก์ชันที่ 1: `count_descendants(name)` — นับลูกหลาน
```python
def count_descendants(name):
    total = 0
    for child in children[name]:
        total = total + 1 + count_descendants(child)
    return total
```
แปลเป็นภาษาคน: **"ลูกหลานของฉัน = ลูกแต่ละคน (นับ 1) + ลูกหลานของลูกคนนั้น"**
- **จุดหยุด:** คนที่ไม่มีลูก → loop ไม่ทำงานเลย → คืน 0
- **เปรียบเทียบ:** ทวดอยากรู้ว่ามีลูกหลานกี่คน ทวดไม่ต้องนับเองทั้งหมด แค่โทรถามลูกแต่ละคนว่า "บ้านเธอมีลูกหลานกี่คน" ลูกก็ไปโทรถามลูกของตัวเองต่อ ไล่ลงไปเรื่อย ๆ แล้วตัวเลขค่อยส่งกลับขึ้นมา

**ลองไล่ด้วยมือ: `count_descendants("พ่อ")`**
```
count("พ่อ")
 ├─ ลูก "ฉัน":     1 + count("ฉัน")     → count("ฉัน") ไม่มีลูก = 0  → ได้ 1
 └─ ลูก "น้องมิว": 1 + count("น้องมิว") → 0                         → ได้ 1
 รวม = 1 + 1 = 2 ✅
```
**`count_descendants("ปู่")`** = (1 + count(ลุง)=2) + (1 + count(พ่อ)=2) + (1 + count(อา)=0) = 3 + 3 + 1 = **7** ✅

#### ฟังก์ชันที่ 2: `ancestors(name)` — สายบรรพบุรุษ
```python
def ancestors(name):
    parent = find_parent(name)
    if parent is None:
        return [name]
    return [name] + ancestors(parent)
```
แปลเป็นภาษาคน: **"สายของฉัน = ตัวฉัน + สายของพ่อแม่ฉัน"**
- **จุดหยุด:** หาพ่อแม่ไม่เจอ (= ถึงทวดแล้ว) → คืนแค่ `[ชื่อตัวเอง]`
- `[name] + [...]` = เอาลิสต์ 2 อันมาต่อกัน

**ลองไล่ด้วยมือ: `ancestors("ฉัน")`** (ลงไปก่อน แล้วคำตอบค่อยต่อกันตอนขากลับ)
```
ancestors("ฉัน")  = ["ฉัน"] + ancestors("พ่อ")
ancestors("พ่อ")  = ["พ่อ"] + ancestors("ปู่")
ancestors("ปู่")  = ["ปู่"] + ancestors("ทวด")
ancestors("ทวด")  = ["ทวด"]                 ← จุดหยุด
ขากลับ: ["ปู่","ทวด"] → ["พ่อ","ปู่","ทวด"] → ["ฉัน","พ่อ","ปู่","ทวด"] ✅
```

`find_parent(name)` เป็นตัวช่วย (ไม่ใช่ recursion): ไล่ดูทุกคนใน dict ว่าใครมีชื่อนี้อยู่ในรายชื่อลูก

#### ฟังก์ชันที่ 3: `show_tree(name, parent_item)` — วาดแผนผัง
```python
def show_tree(name, parent_item):
    item = tree.insert(parent_item, "end", text=name, open=True)
    for child in children[name]:
        show_tree(child, item)
```
- ใส่ชื่อนี้ลง Treeview **ใต้** `parent_item` → ได้ `item` (รหัสของแถวใหม่) กลับมา
- แล้วเรียกตัวเองให้ใส่ลูกแต่ละคน **ใต้ item ของเรา**
- `""` = ชั้นบนสุด จึงเริ่มด้วย `show_tree(ROOT, "")`
- `open=True` = กางกิ่งออกให้เห็นตั้งแต่แรก
- **ข้อดีของ recursion ตรงนี้:** ไม่ว่าครอบครัวจะลึกกี่รุ่น (5 รุ่น หรือ 20 รุ่น) โค้ดก็ยาวเท่าเดิม ถ้าใช้ loop ธรรมดาต้องรู้ล่วงหน้าว่ากี่ชั้น

### ส่วนที่ 2: ฟังก์ชันของปุ่ม

#### `get_selected()` — อ่านชื่อที่ถูกคลิก
```python
item = tree.focus()
...
return tree.item(item, "text")
```
- `tree.focus()` คืนรหัสของแถวที่เลือกอยู่ (ถ้ายังไม่เลือกได้ `""`)
- `tree.item(item, "text")` อ่านข้อความ (ชื่อ) ของแถวนั้น
- ทำเป็นฟังก์ชันแยก เพราะ 3 ปุ่มใช้เหมือนกัน (ไม่ต้องเขียนซ้ำ 3 ที่)

#### `on_add_child()` — เพิ่มลูก
```python
children[parent].append(new_name)
children[new_name] = []
refresh_tree()
```
ต้องทำ **2 อย่าง**: (1) ใส่ชื่อใหม่ในรายชื่อลูกของพ่อแม่ (2) สร้างช่องของคนใหม่ใน dict เป็นลิสต์ว่าง — ถ้าลืมข้อ 2 ตอน `show_tree` ไปถึงคนใหม่จะเกิด `KeyError` เพราะหาชื่อใน dict ไม่เจอ

#### `refresh_tree()` — วาดใหม่ทั้งหมด
ลบแถวบนสุด (ลบแล้วแถวลูกข้างใต้หายตามไปด้วย) แล้วเรียก `show_tree(ROOT, "")` ใหม่

## 5. ลำดับการทำงานทั้งหมด

```
เปิดโปรแกรม → show_tree("ทวด") → ใส่ทวด → เรียกตัวเองใส่ลูก → ใส่หลาน → ... → รอ
   ├─ "นับลูกหลาน" → ยังไม่คลิกชื่อ? เตือน

```

## 6. คำถามที่อาจารย์อาจถาม + แนวตอบ

**ถาม: Recursion คืออะไร?**
ตอบ: คือฟังก์ชันที่เรียกตัวเองครับ ใช้แก้ปัญหาที่แบ่งเป็นปัญหาเล็กแบบเดียวกันได้ เช่น นับลูกหลานของทวด = นับลูกแต่ละคน บวกลูกหลานของลูกคนนั้น ซึ่งก็คือปัญหาเดิมแต่เล็กลง ต้องมีจุดหยุดเสมอ ในโปรแกรมผมคือคนที่ไม่มีลูก

**ถาม: ถ้าไม่มีจุดหยุดจะเกิดอะไรขึ้น?**
ตอบ: ฟังก์ชันจะเรียกตัวเองไม่จบ ทุกครั้งที่เรียกจะกินหน่วยความจำส่วนที่เรียกว่า **Call Stack (คอล-สแต็ก)** จนเต็ม Python จะหยุดแล้วแจ้ง `RecursionError` ครับ

**ถาม: ใช้ loop แทน recursion ได้ไหม?**
ตอบ: ได้ครับ แต่ต้องสร้าง Stack หรือ Queue เก็บคนที่ยังไม่ได้นับเอง (เหมือน BFS ในโปรเจคนำทาง) โค้ดจะยาวกว่า สำหรับข้อมูลแบบต้นไม้ recursion เขียนสั้นและอ่านเข้าใจง่ายกว่า แต่ loop ประหยัดหน่วยความจำกว่าและไม่มีปัญหาเรื่องลึกเกิน 1,000 ชั้น

**ถาม: Tree ต่างจาก Graph ยังไง?**
ตอบ: Tree เป็น Graph แบบพิเศษครับ มีรากเดียว แต่ละจุดมีพ่อแม่ได้แค่ 1 และไม่มีทางวนกลับ ส่วน Graph ทั่วไปเชื่อมกันยังไงก็ได้ วนได้

**ถาม: ในชีวิตจริง ครอบครัวมีพ่อและแม่ 2 คน ทำไมโปรแกรมให้มีพ่อแม่ได้คนเดียว?**
ตอบ: เป็นข้อจำกัดของ Tree ครับ ผมเลยเก็บแค่ฝั่งเดียว (ฝั่งพ่อ) ถ้าจะเก็บทั้งสองฝั่ง โครงสร้างจะไม่ใช่ Tree แล้ว ต้องใช้ Graph แบบมีทิศทาง ซึ่งเป็นจุดที่ผมอยากพัฒนาต่อ

**ถาม: Tree ใช้ที่ไหนอีกในคอมพิวเตอร์?**
ตอบ: โฟลเดอร์ในเครื่อง, โครงสร้างหน้าเว็บ HTML, เมนูที่มีเมนูย่อย, แผนผังองค์กร และ Binary Search Tree ที่ใช้ค้นหาข้อมูลเร็ว ๆ ครับ

**ถาม: `find_parent` เร็วไหม?**
ตอบ: ไม่เร็วครับ ต้องไล่ดูทุกคน (O(n)) และ `ancestors` เรียก find_parent ทุกชั้น ถ้าอยากเร็วขึ้นควรเก็บ dict อีกอัน ชื่อ → พ่อแม่ ไว้ด้วย จะหาได้ทันที

## 7. จุดอ่อนและวิธีพัฒนาต่อ

- **มีพ่อแม่ได้แค่คนเดียว** → เปลี่ยนโครงสร้างให้เก็บได้ทั้งพ่อและแม่ (กลายเป็น Graph)
- **ปิดโปรแกรมแล้วคนที่เพิ่มหาย** → บันทึก `children` ลงไฟล์ JSON
- **ลบหรือแก้ชื่อไม่ได้** → ตอนลบต้องคิดด้วยว่าลูกของคนนั้นจะไปอยู่ที่ไหน
- **ชื่อห้ามซ้ำ** (มี "น้องมิว" ได้แค่คนเดียว) → ใช้รหัสประจำตัวแทนชื่อ
- **`find_parent` ช้าถ้าญาติเยอะ** → เก็บ dict ชื่อ → พ่อแม่ เพิ่มอีกอัน
- **ไม่บอกคำเรียกญาติ** → เพิ่มฟังก์ชันบอกว่า "คนนี้เป็นอะไรกับฉัน" (เช่น ลูกพี่ลูกน้อง)

## 8. แบบฝึก (ทำเองก่อนดูโค้ด)

1. **ทำมือบนกระดาษ:** ไล่ `count_descendants("ทวด")` ทีละชั้นแบบตัวอย่าง ต้องได้ 11
2. **ทำใน Terminal:** เขียน recursion นับถอยหลัง
   ```python
   def countdown(n):
       if n == 0:
           print("ปล่อยจรวด!")
           return
       print(n)
       countdown(n - 1)
   ```
   แล้วลองเรียก `countdown(5)` จากนั้นลองลบ 2 บรรทัดของ `if` ออก ดูว่าเกิด error อะไร
3. เพิ่มฟังก์ชัน `count_children(name)` ที่นับ **เฉพาะลูก** (ไม่นับหลาน) — ข้อนี้ไม่ต้องใช้ recursion ใช้แค่ `len()`
4. **(ท้าทาย)** เขียน recursion `generations(name)` บอกว่าจากคนนี้ลงไปมีกี่รุ่น (ทวดต้องได้ 4: ทวด-ปู่-พ่อ-ฉัน) คำใบ้: คนไม่มีลูก = 1 รุ่น, คนมีลูก = 1 + รุ่นที่มากที่สุดของลูก

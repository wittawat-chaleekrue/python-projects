## 1. โปรแกรมนี้ทำอะไร

- **เพิ่มวิชา**: กรอกชื่อวิชา วันสอบ และจำนวนบทที่ต้องอ่าน

## 4. อธิบายโค้ดทีละส่วน

### ส่วนหัว

```python
import tkinter as tk
from tkinter import messagebox
from datetime import date, datetime
import json
import os
```
- `tkinter` = เครื่องมือสร้างหน้าต่าง, `messagebox` = หน้าต่างเด้งเตือน
- `from datetime import date, datetime` = จากกล่องเครื่องมือ `datetime` หยิบมา 2 ชิ้น:
  - `date` = ใช้หา "วันนี้" และเก็บวันที่
  - `datetime` = ใช้แปลงข้อความเป็นวันที่
- `json` = เก็บข้อมูลลงไฟล์, `os` = เช็คว่ามีไฟล์ไหม

```python
FILE_NAME = "plans.json"
```
ชื่อไฟล์เก็บข้อมูล (ตัวใหญ่หมด = ค่าคงที่ ไม่เปลี่ยน)

### ส่วนที่ 1: อ่าน/บันทึกไฟล์

```python
def load_plans():
    if os.path.exists(FILE_NAME):
        with open(FILE_NAME, "r", encoding="utf-8") as f:
            return json.load(f)
    return []

def save_plans():
    with open(FILE_NAME, "w", encoding="utf-8") as f:
        json.dump(plans, f, ensure_ascii=False, indent=2)
```
- `load_plans` = ถ้ามีไฟล์ (`exists` = มีอยู่) ให้เปิดแบบอ่าน (`"r"` = read) แล้วแปลงเป็น list ถ้าไม่มีไฟล์ คืน list ว่าง
- `save_plans` = เปิดไฟล์แบบเขียน (`"w"` = write เขียนทับ) แล้วเท (`dump`) ข้อมูลลงไป
- `encoding="utf-8"` = ให้อ่านเขียนภาษาไทยได้, `ensure_ascii=False` = เก็บภาษาไทยเป็นภาษาไทย, `indent=2` = จัดย่อหน้าให้อ่านง่าย

```python
plans = load_plans()
```
เปิดโปรแกรมปุ๊บ โหลดแผนเดิมจากไฟล์ทันที

**หน้าตาข้อมูล 1 วิชา** (dictionary):
```python
{"subject": "คณิต", "exam_date": "2026-11-20", "chapters": 8, "done_days": ["2026-10-18", "2026-10-19"]}
```
`done_days` = list ของวันที่ที่ติ๊กว่าอ่านแล้ว นับจำนวนชิ้น = อ่านไปกี่วัน

### ส่วนที่ 2: คำนวณวันที่ (หัวใจของโปรแกรม)

```python
def days_left(exam_date_text):
    exam_date = datetime.strptime(exam_date_text, "%Y-%m-%d").date()
    return (exam_date - date.today()).days
```

**ปัญหา:** สิ่งที่ผู้ใช้พิมพ์ `"2026-11-20"` เป็นแค่ **ข้อความ** คอมไม่รู้ว่าเป็นวันที่ เอามาลบกันไม่ได้

**วิธีแก้:** แปลงข้อความเป็น "วันที่จริง" ก่อน
- `strptime` อ่านว่า "สเตร-พี-ไทม์" มาจาก **string parse time** = แยกอ่านข้อความให้เป็นเวลา (`parse` พาร์ส = แยกวิเคราะห์)
- `"%Y-%m-%d"` คือ "แบบฟอร์ม" บอกว่าข้อความเรียงยังไง:
  - `%Y` = ปี 4 หลัก (**Y**ear เยียร์ = ปี)
  - `%m` = เดือน (**m**onth มันธ์ = เดือน)
  - `%d` = วัน (**d**ay เดย์ = วัน)
- `.date()` = เอาเฉพาะส่วนวันที่ ไม่เอาเวลา

**ลบวันที่:** `exam_date - date.today()` = วันสอบ ลบ วันนี้ ได้ระยะห่าง แล้ว `.days` ดึงออกมาเป็น**จำนวนวัน**

> ตัวอย่าง: วันนี้ 18 ต.ค. 2026, สอบ 20 พ.ย. 2026 → เหลือ 33 วัน

> เปรียบเทียบ: เหมือนเราต้องแปลงคำว่า "ยี่สิบ" ให้เป็นเลข 20 ก่อน ถึงจะเอาไปลบเลขได้

### ส่วนที่ 3: ฟังก์ชันที่ทำงานเมื่อกดปุ่ม

#### `add_plan()` — กดปุ่ม "เพิ่มวิชา"

ดึงค่าจาก 3 ช่องกรอก (`.get()` = เอามา, `.strip()` = ตัดช่องว่างหัวท้าย) แล้ว**ตรวจสอบทีละข้อ** ถ้าผิดตรงไหนก็เตือนแล้ว `return` ออกเลย

**ตรวจ 1: ชื่อวิชาว่างไหม**
```python
if subject == "":
```

**ตรวจ 2: จำนวนบทเป็นตัวเลขไหม** — ได้รู้จัก `try` / `except`
```python
try:
    chapters = int(chapters_text)
except ValueError:
    messagebox.showwarning("แจ้งเตือน", "จำนวนบทต้องเป็นตัวเลข เช่น 8")
    return
```
- ของที่พิมพ์ในช่องกรอกเป็น**ข้อความ**เสมอ แม้จะพิมพ์ `8` ก็ได้ข้อความ `"8"` ต้องแปลงด้วย `int()` (จำนวนเต็ม) ก่อนเอาไปหาร
- ถ้าผู้ใช้พิมพ์ `"แปด"` → `int("แปด")` แปลงไม่ได้ → เกิด **ValueError** (แวล-ลิว เออ-เร่อ = ค่าผิดรูปแบบ)
- `try` = "**ลอง**แปลงดูนะ" / `except ValueError` = "**ถ้า**พังเพราะค่าผิดรูปแบบ ให้มาทำตรงนี้แทน" → เตือนผู้ใช้ โปรแกรมไม่ค้าง

> เปรียบเทียบ: ลองเปิดประตู (try) ถ้าล็อกอยู่ (error) ก็ไปเคาะเรียกคนแทน (except) ไม่ใช่ยืนนิ่งค้าง

**ตรวจ 3: วันที่เขียนถูกแบบไหม** — ใช้ `try`/`except` เหมือนกัน ถ้าพิมพ์ `20/11/2026` แทน `2026-11-20` → `strptime` อ่านไม่ออก → ValueError → เตือน

**ตรวจ 4: วันสอบผ่านไปแล้วหรือยัง**
```python
if left < 0:
```
ถ้าเหลือติดลบ = สอบไปแล้ว ไม่ให้เพิ่ม

**ผ่านทุกด่าน → บันทึก**
```python
new_plan = {"subject": subject, "exam_date": exam_text, "chapters": chapters, "done_days": []}
plans.append(new_plan)
save_plans()
```
สร้าง dictionary วิชาใหม่ (ยังไม่เคยอ่าน `done_days` เลยว่าง) → ต่อท้าย list → บันทึกไฟล์ → ล้างช่องกรอก → วาดรายการใหม่

#### `refresh_list()` — วาดรายการวิชาใหม่

```python
listbox.delete(0, tk.END)
today = str(date.today())

for plan in plans:
    left = days_left(plan["exam_date"])
```
- ล้างรายการเดิม แล้ว**วนลูป**ทีละวิชา
- `str(date.today())` = วันนี้ แปลงเป็นข้อความ เช่น `"2026-10-18"` (แปลงเพื่อให้เทียบกับข้อมูลใน `done_days` ที่เก็บเป็นข้อความได้)

```python
    if left > 0:
        per_day = round(plan["chapters"] / left, 1)
        text = f"{plan['subject']} | สอบอีก {left} วัน | ควรอ่านวันละ {per_day} บท"
    elif left == 0:
        text = f"{plan['subject']} | สอบวันนี้! สู้ๆ"
    else:
        text = f"{plan['subject']} | สอบไปแล้ว"
```
**if-elif-else แบ่ง 3 กรณี:**
- `if left > 0` = ยังไม่ถึงวันสอบ → คำนวณ **บทต่อวัน = จำนวนบท ÷ วันที่เหลือ** (`/` คือหาร)
  - `per day` (เพอร์ เดย์) = ต่อวัน
  - `round(..., 1)` = ปัดเหลือทศนิยม 1 ตำแหน่ง เช่น 0.24242 → 0.2
- `elif left == 0` (เอล-อิฟ มาจาก **else if** = ไม่ใช่ แต่ถ้า...) = สอบวันนี้
  - **ทำไมต้องแยกกรณีนี้?** ถ้า left = 0 แล้วเอาไปหาร = **หารด้วยศูนย์** ซึ่งคณิตศาสตร์ทำไม่ได้ โปรแกรมจะ error (ZeroDivisionError)
- `else` = กรณีที่เหลือ (ติดลบ) = สอบไปแล้ว

```python
    text = text + f" | อ่านแล้ว {len(plan['done_days'])} วัน"
    if today in plan["done_days"]:
        text = text + " ✓"
```
- นับจำนวนวันที่อ่านแล้ว = จำนวนชิ้นใน `done_days` (`len` = ความยาว)
- `today in plan["done_days"]` = วันนี้**อยู่ใน** list วันที่อ่านแล้วไหม (`in` อิน = อยู่ใน) ถ้าใช่ เติม ✓

```python
    listbox.insert(tk.END, text)
```
ใส่บรรทัดลงกล่องรายการ (`insert` = ใส่, `END` = ท้ายสุด)

#### `mark_done()` — กดปุ่ม "วันนี้อ่านแล้ว ✓"

```python
selected = listbox.curselection()
if len(selected) == 0:
    ...เตือนให้เลือกก่อน
    return

index = selected[0]
plan = plans[index]
```
- `curselection` อ่านว่า "เคอร์-ซี-เล็ค-ชั่น" มาจาก **current selection** = สิ่งที่เลือกอยู่ตอนนี้ → ได้ลำดับแถวที่ผู้ใช้คลิก
- ถ้าไม่ได้คลิกอะไรเลย ได้ค่าว่าง → เตือน
- `selected[0]` = เอาลำดับแถวที่เลือก (`index` = ลำดับที่)
- **เคล็ดลับ:** แถวที่ 0 ในกล่องรายการ = วิชาที่ 0 ใน list `plans` เพราะตอนวาด เราวาดเรียงตามลำดับใน `plans` ทุกครั้ง ลำดับจึงตรงกันพอดี

```python
if today in plan["done_days"]:
    ...เตือน "วันนี้ติ๊กวิชานี้ไปแล้ว"
    return

plan["done_days"].append(today)
save_plans()
refresh_list()
```
- กันติ๊กซ้ำในวันเดียวกัน (ไม่งั้นกดรัวๆ ก็นับเป็นอ่านหลายวัน = โกงตัวเอง)
- ถ้ายังไม่ติ๊ก → เพิ่มวันนี้ต่อท้าย → บันทึก → วาดใหม่

#### `delete_plan()` — กดปุ่ม "ลบวิชา"

หาแถวที่เลือกแบบเดียวกับ `mark_done` แล้ว:
```python
sure = messagebox.askyesno("ยืนยัน", f"ลบวิชา {plans[index]['subject']} ใช่ไหม?")
if sure:
    plans.pop(index)
```
- `askyesno` = ถามยืนยันก่อน เพราะลบแล้วย้อนไม่ได้
- `plans.pop(index)` = ดึงวิชาที่ลำดับนั้นออกจาก list (ลบ) → บันทึก → วาดใหม่

## 5. ลำดับการทำงานทั้งหมด

```
เปิดโปรแกรม → โหลด plans.json → วาดรายการ → รอกดปุ่ม
   ├─ "เพิ่มวิชา"       → ตรวจ 4 ด่าน (ชื่อ / ตัวเลข / รูปแบบวันที่ / วันผ่านไปยัง)
   │                     → ผ่าน: ต่อท้าย list → บันทึก → วาดใหม่
   ├─ "วันนี้อ่านแล้ว ✓" → เลือกแถวยัง? → ติ๊กไปแล้วยัง? → เพิ่มวันนี้ → บันทึก → วาดใหม่
   └─ "ลบวิชา"          → เลือกแถวยัง? → ถามยืนยัน → ลบ → บันทึก → วาดใหม่

ตอนวาด แต่ละวิชาคำนวณ: วันที่เหลือ = วันสอบ − วันนี้
   ├─ > 0 → บทต่อวัน = บท ÷ วันที่เหลือ
   ├─ = 0 → "สอบวันนี้" (กันหารด้วยศูนย์)
   └─ < 0 → "สอบไปแล้ว"
```

## 6. คำถามที่อาจารย์อาจถาม + แนวตอบ

**ถาม: คำนวณวันที่เหลือยังไง?**
ตอบ: ข้อความที่ผู้ใช้พิมพ์คอมยังไม่รู้ว่าเป็นวันที่ ผมเลยใช้ strptime แปลงเป็นวันที่ก่อน แล้วเอาวันสอบลบวันนี้ จะได้ระยะห่าง แล้วดึงจำนวนวันออกมาด้วย .days ครับ

**ถาม: try/except ใช้ทำอะไร?**
ตอบ: ใช้ดักข้อผิดพลาดครับ เช่น ผู้ใช้พิมพ์จำนวนบทเป็นตัวหนังสือ int() จะแปลงไม่ได้และเกิด ValueError ถ้าไม่ดักไว้โปรแกรมจะพัง ผมเลยลองแปลงใน try ถ้าพังให้ไปเตือนผู้ใช้ใน except แทน

**ถาม: ทำไมต้องแยกกรณีสอบวันนี้ (left == 0)?**
ตอบ: เพราะสูตรคือจำนวนบทหารด้วยวันที่เหลือ ถ้าวันที่เหลือเป็น 0 จะเป็นการหารด้วยศูนย์ ซึ่งทำไม่ได้และโปรแกรมจะ error ครับ

**ถาม: ทำไมโปรแกรมรู้ว่าแถวที่คลิกคือวิชาไหน?**
ตอบ: ตอนวาดรายการ ผมวนลูปตามลำดับใน list plans ทุกครั้ง แถวที่ 0 บนจอจึงตรงกับวิชาที่ 0 ใน list เสมอ เอาเลขแถวไปหยิบใน list ได้เลยครับ

**ถาม: จุดอ่อน / จะพัฒนาต่อยังไง?**
- ต้องพิมพ์วันที่แบบ ปี-เดือน-วัน เอง ผู้ใช้อาจสับสน → ใช้ปฏิทินให้คลิกเลือก
- ติ๊กได้แค่ "อ่านแล้ว" ไม่รู้ว่าอ่านไปกี่บท → ให้กรอกจำนวนบทที่อ่านจริง แล้วคำนวณบทที่เหลือ/วันใหม่ทุกวัน
- ไม่เรียงวิชาตามวันสอบ → เรียงให้วิชาที่ใกล้สอบที่สุดอยู่บนสุด
